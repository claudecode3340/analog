Before you fit any model, look at the data. A single picture can show a curve where you expected a line, an outlier that will drag your fit, or two groups that should be modelled separately. This lesson teaches matplotlib, the plotting library behind every figure in the ISLP labs, from a first scatter plot to a faithful copy of ISLP's Figure 2.1.

You'll use NumPy I (arrays, linspace, masks) · NumPy II (random generators, broadcasting, polyfit)

By the end of this lesson you can

  • create a figure and axes with fig, ax = plt.subplots() and explain what each object is for;
  • draw line plots, scatter plots, histograms, bar charts, box plots, heatmaps and contour plots;
  • label axes (with units), add titles and legends, set limits and scales, and choose colours, markers and line styles;
  • arrange several plots in a grid with shared axes, and save a figure to a file;
  • reproduce ISLP Figure 2.1 (sales against TV, radio and newspaper budgets with fitted lines) from Advertising.csv.
In matplotlib, a plot consists of a figure and one or more axes. You can think of the figure as the blank canvas upon which one or more plots will be displayed.

1. Why look first: four datasets, one set of statistics

In 1973 the statistician Francis Anscombe built four small datasets that agree on almost every summary number: the same mean of \(x\) (9), the same mean of \(y\) (7.50), the same variance, the same correlation (0.816) and the same least-squares line, \(\hat y = 3.00 + 0.500x\). Here they are, checked with NumPy.

import numpy as np
import matplotlib.pyplot as plt          # the usual nickname
from matplotlib.pyplot import subplots   # ISLP's style: import just this one function

x123 = np.array([10, 8, 13, 9, 11, 14, 6, 4, 12, 7, 5])
x4 = np.array([8, 8, 8, 8, 8, 8, 8, 19, 8, 8, 8])
ys = [np.array([8.04, 6.95, 7.58, 8.81, 8.33, 9.96, 7.24, 4.26, 10.84, 4.82, 5.68]),
      np.array([9.14, 8.14, 8.74, 8.77, 9.26, 8.10, 6.13, 3.10, 9.13, 7.26, 4.74]),
      np.array([7.46, 6.77, 12.74, 7.11, 7.81, 8.84, 6.08, 5.39, 8.15, 6.42, 5.73]),
      np.array([6.58, 5.76, 7.71, 8.84, 8.47, 7.04, 5.25, 12.50, 5.56, 7.91, 6.89])]
xs = [x123, x123, x123, x4]
This setup cell runs first whenever you run any cell of this lesson. matplotlib.pyplot is the part of matplotlib you talk to; everyone calls it plt. ISLP instead imports only the subplots function. Both styles appear in this lesson so that you can read either.
for k in range(4):
    x, y = xs[k], ys[k]
    slope, intercept = np.polyfit(x, y, 1)      # least-squares line (from NumPy II)
    r = np.corrcoef(x, y)[0, 1]
    print(f"set {k+1}: mean x={x.mean():.2f}  mean y={y.mean():.2f}  "
          f"var y={y.var(ddof=1):.2f}  r={r:.3f}  line: y = {intercept:.2f} + {slope:.3f} x")
Read the output: four lines of nearly identical numbers. If you only looked at summaries you would conclude the four datasets are the same. Now plot them.

The four datasets share their means, variances, correlation and fitted line. What will their scatter plots look like?

  1. Four nearly identical clouds of points
  2. Four clouds with different slopes
  3. Four completely different shapes
Summary numbers throw away almost everything about the shape of the data. The plots show a noisy line, a smooth curve, a perfect line spoiled by one outlier, and a vertical stack plus one extreme point. Only the first is a good fit for a straight line.
fig, axes = plt.subplots(1, 4, figsize=(12, 3), sharex=True, sharey=True)
grid = np.linspace(3, 20, 2)
for k in range(4):
    ax = axes[k]
    ax.scatter(xs[k], ys[k], color="C0")
    ax.plot(grid, 3 + 0.5 * grid, color="C1")      # the shared fitted line
    ax.set_title(f"Anscombe set {k+1}")
    ax.set_xlabel("x")
axes[0].set_ylabel("y")
fig.tight_layout()
Read the output: one figure with four panels side by side. Set 1 suits a straight line. Set 2 is a curve (a line is the wrong model). Set 3 is a perfect line with one outlier pulling the fit. In set 4 a single point creates the whole slope. Everything in this cell (subplots, scatter, plot, titles, labels, tight_layout) is explained in the sections below. The lesson: always plot first.

2. Figure and axes: the two objects you work with

A matplotlib picture is made of two kinds of object. The figure is the whole canvas: its size, its background, the file it is saved to. An axes is one plotting area inside it, with its own x-axis, y-axis, ticks, labels, title and data. A figure can hold several axes. (ISLP warns that “axes” here is not the plural of “axis”: one axes object contains two axis objects, the x-axis and the y-axis.)

You make both at once with plt.subplots(). It returns a tuple of two things, and you unpack it into two names, exactly as ISLP does:

rng = np.random.default_rng(1)
x = rng.standard_normal(100)
y = rng.standard_normal(100)

fig, ax = subplots(figsize=(5, 4))   # figsize = (width, height) in inches
# ISLP In[39]: ax.plot draws a LINE plot by default
ax.plot(x, y);
Read the output: a tangle of lines. ax.plot joins consecutive points with straight lines, which only makes sense when the points are in order (a time series, a function). These points are random, so joining them makes no sense: we want dots. The semicolon at the end hides a line of text that ax.plot would otherwise print (a list describing the line object); it does not affect the picture. ISLP ends plotting lines with ; for this reason.
New in this lesson · unpacking a tuple

fig, ax = subplots() is short for output = subplots(), then fig = output[0] and ax = output[1] (ISLP In[40]). Python lets you unpack any tuple or list into the same number of names: a, b = (3, 4) gives a = 3 and b = 4. You saw the same trick in NumPy II with np.linalg.lstsq.

To draw dots instead of lines, give ax.plot a third argument, a format string: 'o' means “circle markers, no line”. Or use ax.scatter, which is designed for scatter plots:

fig, axes = plt.subplots(1, 2, figsize=(9, 3.6))
axes[0].plot(x, y, 'o')                  # ISLP In[41]
axes[0].set_title("ax.plot(x, y, 'o')")
axes[1].scatter(x, y, marker='o')        # ISLP In[42]
axes[1].set_title("ax.scatter(x, y)")
fig.tight_layout()
Read the output: two scatter plots of the same points. They look alike. The difference: scatter can give every point its own size and colour (you will use that soon), while plot is faster for many points of one style.

Here is a fully labelled figure. Every part you will configure is named on it, with the method that controls it:

t = np.linspace(0, 1, 200)
fig, ax = plt.subplots(figsize=(8, 4.2))
ax.plot(t, np.sin(2*np.pi*2*t), label="2 Hz sine")
ax.plot(t, 0.5*np.cos(2*np.pi*3*t), '--', label="3 Hz cosine")
ax.set_xlabel("time (s)"); ax.set_ylabel("amplitude (V)")
ax.set_title("Two test signals"); ax.legend(loc="upper right")
red = dict(color="#C0392F", fontsize=9.5, xycoords="axes fraction", annotation_clip=False,
           arrowprops=dict(arrowstyle="->", color="#C0392F"))
ax.annotate("title: ax.set_title", xy=(0.62, 1.04), xytext=(1.04, 1.04), **red)
ax.annotate("legend: ax.legend", xy=(0.99, 0.86), xytext=(1.04, 0.86), **red)
ax.annotate("a line: ax.plot", xy=(0.95, -0.59), xytext=(1.04, 0.50),
            **{**red, "xycoords": "data", "textcoords": "axes fraction"})   # xy in data units
ax.annotate("tick labels: ax.set_xticks", xy=(0.80, -0.06), xytext=(1.04, 0.14), **red)
ax.annotate("x-axis label: ax.set_xlabel", xy=(0.55, -0.13), xytext=(1.04, -0.10), **red)
fig.text(0.01, 0.01, "the whole canvas is the figure: fig", fontsize=9.5, color="#1C7650")
fig.tight_layout()
Read the output: the red notes and arrows name the parts of the axes; the green note names the figure. ax.annotate writes text at a position; xycoords="axes fraction" means (0, 0) is the bottom-left of the plotting area and (1, 1) its top-right. You will rarely annotate, but you will use every labelled part constantly.

Two ways to plot, and why we use one. You will meet code like plt.plot(x, y), plt.xlabel("x"): the “pyplot” style, which draws on whichever axes is current. It is fine for a quick look, but it becomes confusing with several panels. This guide (and ISLP) uses the object style: fig, ax = plt.subplots(), then ax.plot, ax.set_xlabel. Note the names: plt.xlabel but ax.set_xlabel.

4. Plotting a function: sample it finely

To plot a function \(f(x)\), make a fine grid of \(x\) values with np.linspace, compute \(f\) on the whole grid at once, and join the points with ax.plot. Matplotlib only ever draws straight segments between the points you give it, so the curve looks smooth only if the points are close together.

We plot \(\sin(2\pi\cdot 3x)\) on \([0, 1]\) (three full cycles) using only 7 evenly spaced points from np.linspace(0, 1, 7). What will we see?

  1. A smooth sine wave with three cycles
  2. A flat or jagged line that looks nothing like a sine
  3. An error, because 7 points are not enough
Seven samples over three cycles is about 2.3 samples per cycle, barely above the Nyquist rate, and matplotlib joins them with straight lines. Here every sample falls exactly on a zero crossing, so the picture is a flat line that looks nothing like a sine. With 200 points the curve is smooth.
f = lambda x: np.sin(2 * np.pi * 3 * x)     # a tiny one-line function (explained below)
x_coarse = np.linspace(0, 1, 7)
x_fine = np.linspace(0, 1, 200)
fig, ax = plt.subplots(figsize=(7, 3.2))
ax.plot(x_fine, f(x_fine), label="200 points")
ax.plot(x_coarse, f(x_coarse), 'o-', label="7 points")
ax.set_xlabel("x"); ax.set_ylabel("f(x)")
ax.legend();
Read the output: the 200-point curve is a smooth sine; the 7-point version is almost flat, because the samples land at \(x=0, 1/6, 2/6,\dots\), where \(\sin(2\pi\cdot3x)=\sin(\pi k)\approx0\). f = lambda x: ... defines a function in one line: lambda x: expression is a nameless function that takes x and returns the expression. It is the same as def f(x): return np.sin(2*np.pi*3*x). You will meet lambda again in pandas.

This is sampling and interpolation. Plotting is reconstruction with a first-order hold: straight lines between samples. If you sample a function below about twice its highest frequency you see aliasing, exactly as in your signals course. A safe habit: a few hundred points across the plotted range.

5. The plot types you will use

Scatter plots with colour and size

ax.scatter(x, y, c=values, s=sizes, alpha=0.5, cmap="viridis") colours each point by a number (through a colormap), sizes it by another, and makes points semi-transparent with alpha (0 invisible, 1 solid) so that overlapping points show up darker. fig.colorbar(...) adds the colour key.

rng = np.random.default_rng(0)
x = rng.uniform(0, 10, 300)
y = 2 + 0.5 * x + rng.normal(0, 1, 300)
fig, ax = plt.subplots(figsize=(6, 4))
pts = ax.scatter(x, y, c=y - (2 + 0.5 * x), cmap="coolwarm", s=18, alpha=0.8)
fig.colorbar(pts, ax=ax, label="residual (y minus true line)")
ax.set_xlabel("x"); ax.set_ylabel("y");
Read the output: points above the true line are red, points below are blue, and the colour bar maps colour back to the number. This is how you will colour points by class (in classification) or by error (in regression diagnostics).

Histograms: the shape of one variable

A histogram splits the range of a variable into bins and draws a bar for how many values fall in each. ax.hist(values, bins=12). The number of bins changes the picture a lot:

Start with 3 bins: all you learn is that low mpg is more common than high. Around 12–20 bins you see its real shape: most cars between 15 and 30 mpg, a long tail to the right. At 80 bins the picture is mostly noise. ISLP uses bins=12 for this very variable.
z = np.random.default_rng(2).normal(loc=20, scale=5, size=1000)
fig, axes = plt.subplots(1, 2, figsize=(9, 3.2))
axes[0].hist(z, bins=12, color="C0", edgecolor="white")
axes[0].set_title("bins=12 (counts)")
counts, edges, bars = axes[1].hist(z, bins=30, density=True, color="C2", alpha=0.7)
grid = np.linspace(0, 40, 200)
axes[1].plot(grid, np.exp(-(grid - 20)**2 / (2 * 5**2)) / (5 * np.sqrt(2 * np.pi)), color="C1")
axes[1].set_title("bins=30, density=True")
for a in axes: a.set_xlabel("value")
fig.tight_layout()
print(len(counts), "bins; first edges:", np.round(edges[:3], 2))
Read the output: with density=True the bar heights are scaled so the total area is 1, which lets you overlay a probability density (the orange normal curve with mean 20 and standard deviation 5). ax.hist also returns the counts and the bin edges, which is handy for checking; there are 31 edges for 30 bins.

Bar charts and box plots

ax.bar(names, heights) draws one bar per category. A box plot summarises a distribution in five numbers: the box spans the middle half of the data (25th to 75th percentile), the line inside is the median, the whiskers reach to the furthest points within 1.5 box-lengths, and points beyond are drawn individually as possible outliers. ISLP Figure 1.1 (right) and 1.2 use box plots.

fig, axes = plt.subplots(1, 2, figsize=(9, 3.4))
names = ["America", "Europe", "Japan"]
counts = [245, 68, 79]                      # cars of each origin in ISLP's Auto data
axes[0].bar(names, counts, color=["C0", "C1", "C2"])
axes[0].set_ylabel("number of cars"); axes[0].set_title("A bar chart")
rng = np.random.default_rng(3)
groups = [rng.normal(20, 4, 100), rng.normal(27, 6, 100), rng.normal(30, 5, 100)]
axes[1].boxplot(groups)
axes[1].set_xticks([1, 2, 3], names)        # boxes sit at x = 1, 2, 3
axes[1].set_ylabel("mpg (simulated)"); axes[1].set_title("A box plot")
fig.tight_layout()
Read the output: left, one bar per origin. Right, three simulated groups: you can compare their medians, spreads and outliers at a glance. set_xticks(positions, labels) puts names under the boxes.

Reference lines: axhline, axvline, axline

ax.axhline(0) draws a horizontal line across the whole axes (for example \(y=0\) on a residual plot), ax.axvline(5) a vertical one, and ax.axline((0, b), slope=m) an infinite straight line through a point with a given slope: the easiest way to draw a fitted regression line. ISLP Chapter 3 writes a small helper called abline for the same job.

fig, ax = plt.subplots(figsize=(6, 3.6))
ax.scatter(x, y, s=10, alpha=0.5)
b1, b0 = np.polyfit(x, y, 1)                     # slope, intercept
ax.axline((0, b0), slope=b1, color="C1", linewidth=2, label=f"fit: y = {b0:.2f} + {b1:.2f}x")
ax.axhline(y.mean(), color="gray", linestyle=":", label="mean of y")
ax.axvline(5, color="C2", linestyle="--", label="x = 5")
ax.set_xlabel("x"); ax.set_ylabel("y"); ax.legend(fontsize=8);
Read the output: the fitted line is close to the true line \(y=2+0.5x\) used to simulate the data. The label uses an f-string so the legend shows the actual coefficients.

Heatmaps and contour plots of a function of two variables

ISLP's lab (In[49]–[51]) shows a function \(f(x, y)\) on a grid in two ways. ax.contour(x, y, f) draws lines of equal height, like a topographic map; ax.imshow(f) colours every grid cell (a heatmap). You will see contour plots of loss surfaces in Prince and ISLP Chapter 6. The table f is built by broadcasting, as in NumPy II.

xg = np.linspace(-np.pi, np.pi, 50)
yg = xg
f = np.multiply.outer(np.cos(yg), 1 / (1 + xg**2))   # f[i, j] = cos(y_i) / (1 + x_j^2)
fig, axes = plt.subplots(1, 3, figsize=(12, 3.6))
axes[0].contour(xg, yg, f)
axes[0].set_title("contour (default levels)")
axes[1].contour(xg, yg, f, levels=45)
axes[1].set_title("contour, levels=45")
im = axes[2].imshow(f, origin="lower", extent=[-np.pi, np.pi, -np.pi, np.pi], cmap="viridis")
fig.colorbar(im, ax=axes[2]); axes[2].set_title("imshow (heatmap)")
for a in axes: a.set_xlabel("x"); a.set_ylabel("y")
fig.tight_layout()
Read the output: all three show the same hill: highest at the centre (\(\cos 0/(1+0)=1\)) and negative near the top and bottom edges, where \(\cos y\lt 0\). imshow treats the array like an image, with row 0 at the top; origin="lower" puts row 0 at the bottom, matching the contour plots, and extent labels the axes with real x and y values instead of row and column numbers.

6. Several plots in one figure

plt.subplots(nrows, ncols) returns the figure and an array of axes. With one row or one column the array is 1-D (axes[0], axes[1]…); with several rows and columns it is 2-D, indexed like a NumPy matrix: axes[0, 1] is row 0, column 1. ISLP's example (In[45]–[46]):

What will axes.shape be after fig, axes = subplots(nrows=2, ncols=3)?

  1. (6,)
  2. (2, 3)
  3. (3, 2)
The axes come back in a NumPy array laid out like the grid: 2 rows, 3 columns, so axes[0, 1] is the top-middle panel. (With a single row, subplots(1, 3), the array is 1-D, shape (3,).)
rng = np.random.default_rng(4)
x = rng.standard_normal(100); y = rng.standard_normal(100)
fig, axes = subplots(nrows=2, ncols=3, figsize=(10, 5))
axes[0, 1].plot(x, y, 'o')            # row 0, column 1
axes[1, 2].scatter(x, y, marker='+')  # row 1, column 2
print(type(axes), axes.shape)
Read the output: a 2 × 3 grid with only two panels filled. axes is a NumPy array of shape (2, 3) whose elements are axes objects, so everything you learned about indexing applies.

sharex=True and sharey=True make all panels use the same axis range, so the eye can compare them honestly. fig.suptitle adds a title over the whole figure, and fig.tight_layout() (or plt.subplots(..., layout="constrained")) spaces the panels so labels do not overlap.

Three panels show signals with amplitudes 1, 2 and 4. With sharey=True, how will they look?

  1. The three waves have visibly different heights, on one common y-range from about −4 to 4
  2. All three waves look the same height, each panel scaled to its own data
  3. Only the first panel shows a wave
With a shared y-axis every panel uses the range needed by the largest signal, so the amplitude-1 wave looks small and the amplitude-4 wave fills its panel. Without sharey each panel autoscales and all three would look identical, which hides exactly the difference you want to see.
t = np.linspace(0, 1, 300)
fig, axes = plt.subplots(1, 3, figsize=(10, 3), sharey=True, layout="constrained")
for ax, amp in zip(axes, [1, 2, 4]):
    ax.plot(t, amp * np.sin(2 * np.pi * 2 * t))
    ax.set_title(f"amplitude {amp}")
    ax.set_xlabel("time (s)")
axes[0].set_ylabel("voltage (V)")
fig.suptitle("sharey=True: one common y-axis");
Read the output: only the first panel has y tick labels, because the others share them. zip(axes, [1, 2, 4]) (from Python II) walks through the panels and amplitudes in step. Change sharey=True to False and run again: the three waves now look the same size.

7. Saving a figure

fig.savefig("name.png", dpi=200) writes the figure to a file. The format comes from the extension: .png (pixels, good for the web), .pdf or .svg (vector graphics: sharp at any size, best for reports and LaTeX). dpi (dots per inch) sets the resolution of pixel formats: a 6-inch-wide figure at dpi=200 is 1200 pixels wide. bbox_inches="tight" trims empty margins. ISLP (In[47]) saves at dpi=400.

import os
fig, ax = plt.subplots(figsize=(4, 3))
ax.plot([0, 1, 2], [0, 1, 4], 'o-')
ax.set_xlabel("x"); ax.set_ylabel("x squared")
fig.savefig("my_first_figure.png", dpi=200, bbox_inches="tight")
fig.savefig("my_first_figure.pdf")
print([f for f in os.listdir(".") if f.startswith("my_first")])
Read the output: both files now exist in the working folder (os.listdir(".") lists the files in the current folder). In the browser they live in the page's temporary file system; on your Mac they appear next to your notebook. You can keep changing fig after saving, for example ax.set_xlim(-1, 1), and save again (ISLP In[48]).

8. Reproducing ISLP Figure 2.1

Figure 2.1 opens ISLP Chapter 2: sales of a product in 200 markets, plotted against the advertising budget spent on TV, radio and newspaper, each with a least-squares line. Look at it carefully first.

We need the data in Python. The file Advertising.csv is a table; the pandas lesson teaches tables properly, so here we use just two pandas commands: pd.read_csv loads the file into a table called a DataFrame, and ads["TV"] picks one column, which works with NumPy and matplotlib like an array.

import pandas as pd
ads = pd.read_csv("Advertising.csv", index_col=0)   # the first column is just a row number
print(ads.shape)
ads.head()     # the first five rows
Read the output: 200 markets (rows) and 4 columns: the three budgets in thousands of dollars, and sales in thousands of units. index_col=0 uses the file's first, unnamed column as row labels instead of treating it as data.
Worked example · planning the figure before coding it
Goal: a 1 × 3 grid of scatter plots, same y-axis (sales), red open circles, blue fitted line, labelled axes.
  1. Layout: fig, axes = plt.subplots(1, 3, figsize=(12, 4), sharey=True).Shared y makes the three slopes directly comparable.
  2. Open circles: ax.scatter(x, y, facecolors="none", edgecolors="C1").“none” means an empty inside; C1 is red in this guide's colour cycle.
  3. Fitted line: b1, b0 = np.polyfit(x, y, 1), then ax.axline((0, b0), slope=b1, color="blue", linewidth=3).
  4. Repeat for the three columns with a loop over ["TV", "radio", "newspaper"], labelling each x-axis.
One loop, three panels, about ten lines of code

Look at the book's figure. Which medium do you expect to have the largest fitted slope, measured in extra sales per extra $1000?

  1. TV, because its line rises the most across the panel
  2. Radio
  3. Newspaper
The TV line rises the most across its panel, but its panel spans $300k while radio's spans only $50k. Per $1000, radio's slope (about 0.20) is roughly four times TV's (about 0.048). Always read slopes in the units of the x-axis, not by eye.
fig, axes = plt.subplots(1, 3, figsize=(12, 4), sharey=True)
labels = {"TV": "TV budget ($1000s)", "radio": "Radio budget ($1000s)",
          "newspaper": "Newspaper budget ($1000s)"}
for ax, col in zip(axes, ["TV", "radio", "newspaper"]):
    x, y = ads[col], ads["sales"]
    b1, b0 = np.polyfit(x, y, 1)
    ax.scatter(x, y, facecolors="none", edgecolors="C1", s=22)
    ax.axline((0, b0), slope=b1, color="blue", linewidth=3)
    ax.set_xlim(left=-0.03 * x.max())
    ax.set_xlabel(labels[col])
    ax.set_title(f"slope {b1:.4f} per $1000")
axes[0].set_ylabel("Sales (thousands of units)")
fig.tight_layout()
Read the output: compare with the book's figure above: same clouds, same lines. The titles give the slopes: about 0.0475 extra thousand units of sales per extra $1000 of TV, 0.2025 for radio and 0.0547 for newspaper (ISLP reports these same TV numbers in Chapter 3: intercept 7.03, slope 0.0475). Label every axis, with unitsA reader must understand the plot without your code.
