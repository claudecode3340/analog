Prince's notation, read aloud

Prince writes functions with square brackets: \(\mathrm{f}[x,\bphi]\) instead of \(f(x,\phi)\). The reason is practical. In his book, round brackets always mean "group this", as in \(2(a+b)\). Square brackets always mean "these are the inputs of a function". So when you see \(\mathrm{a}[\theta_{10}+\theta_{11}x]\) in the next chapter, you know straight away that \(\mathrm{a}\) is a function being applied, not a number being multiplied. (How to read the maths covers this convention and lists the common symbols.)

He also uses Greek letters for parameters (the numbers the computer learns) and Latin letters for data (the numbers you are given). Remember the rule: if it is Greek, training will change it.

SymbolSay it as / meaningTiny example
\(\bx,\ x\)"x": the input. Bold \(\bx\) when it is a vector of several numbers, plain \(x\) when it is one number.\(\bx=[5,\,60000]^T\) (age, km)
\(\by,\ y\)"y": the output, the thing we predict.\(y=1.54\)
\(\mathrm{f}[\bullet]\)"f of …": the model, an equation that turns an input into an output. The dot \(\bullet\) is a placeholder for "whatever goes in".\(\mathrm{f}[x]=0.8+0.5x\)
\(\bphi\)"phi" (say "fye" or "fee"; both are common): the list (vector) of all parameters.\(\bphi=[0.82,\,0.52]\)
\(\phi_0,\ \phi_1\)"phi-zero", "phi-one": the intercept and the slope of a line.\(\phi_0=0.82\)
\(I\)"capital I": the number of training examples.\(I=12\)

2.1 The supervised learning recipe

Supervised learning means: you are given examples of inputs together with the right answers, and you want a machine that produces right answers for new inputs. It is called "supervised" because the right answers act like a teacher marking your work.

Prince's running example is a second-hand Toyota Prius. The input is the car's age and mileage; the output is its price. Every input has the same fixed list of numbers in the same order (age first, then mileage), so this kind of data is called structured or tabular data: it would fit in a spreadsheet, one row per car.

Step 1 · the model

A model is an equation that takes an input and returns an output:

Equation 2.1 · a model
\[\by=\mathrm{f}[\bx]\]

Read: "y equals f of x". Feed the input into the equation; out comes the prediction.

Running an input through the model to get a prediction is called inference. (ISLP just calls this "predicting". Engineers say "inference" for the part that runs on the phone or the server after training has finished.)

The equation has a fixed form, for example "a straight line", but it also contains adjustable numbers, the parameters \(\bphi\). Change the parameters and you change which line you get. So we should really write:

Equation 2.2 · a model with parameters
\[\by=\mathrm{f}[\bx,\bphi]\]

Read: "y equals f of x and phi". The input \(\bx\) comes from the world; the parameters \(\bphi\) are chosen by training.

A model is a family; the parameters pick one member. "Straight line" is a family with infinitely many members. \(\phi_0=0.82,\ \phi_1=0.52\) picks out one particular line. Every neural network in this book is the same idea with a much richer family and many more parameters.

Step 2 · the loss

We learn the parameters from a training set of \(I\) pairs \(\{\bx_i,\by_i\}\). To decide which parameters are "good", we need a single number that measures the mismatch between what the model predicts, \(\mathrm{f}[\bx_i,\bphi]\), and what really happened, \(\by_i\). That number is the loss \(L\). A small loss means a good fit. The data are fixed, so the loss depends only on the parameters, and we write it \(L[\bphi]\), a function of \(\bphi\). (Strictly it also depends on the data, \(L[\{\bx_i,\by_i\},\bphi]\), but writing that every time is clumsy, so Prince leaves it out.)

Step 3 · training

Training (also called learning or fitting) means finding the parameters that make the loss as small as possible:

Equation 2.3 · training
\[\hat\bphi=\argmin_{\bphi}\Big[L[\bphi]\Big]\]

Read: "phi-hat is the arg-min over phi of L of phi": the best parameters are whichever \(\bphi\) gives the smallest loss.

Worked example · argmin versus min
Let \(g[\phi]=(\phi-3)^2+1\). Find \(\min_\phi g[\phi]\) and \(\argmin_\phi g[\phi]\).
  1. \((\phi-3)^2\) is never negative, and it is zero only when \(\phi=3\).
  2. So the smallest value of \(g\) is \(0+1=\mathbf{1}\). That is the min.
  3. The place where that smallest value happens is \(\phi=\mathbf{3}\). That is the argmin.Training wants the argmin: we keep the parameters, not the loss value.
\(\min g=1,\quad \argmin g=3\)

Step 4 · testing

A model that fits the training data is not yet a model that works. We must check it on test data: separate examples it never saw during training. Only if it does well there does it generalise, and only then is it ready to deploy. ISLP calls this comparing "training MSE" and "test MSE".

Like calibrating an instrument. A sensor's reading \(y\) depends on a physical quantity \(x\) through a law with two unknown constants (gain and offset). You apply known inputs (the training set), adjust the constants until the readings match (training, by minimising a mismatch), and then check the calibration with inputs you did not use while adjusting (testing). Supervised learning is calibration of a very flexible instrument.

2.2.1 The 1-D linear regression model

Now everything becomes concrete. One input \(x\), one output \(y\), and the simplest interesting family: straight lines.

Equation 2.4 · 1-D linear regression
\[y=\mathrm{f}[x,\bphi]=\phi_0+\phi_1x\]

Read: "y equals phi-zero plus phi-one times x". \(\phi_0\) is the y-intercept (the height where the line crosses \(x=0\)); \(\phi_1\) is the slope (how much \(y\) rises when \(x\) goes up by 1).

Tiny example. With \(\phi_0=1.0,\ \phi_1=-0.4\) and input \(x=2\): \(y=1.0+(-0.4)(2)=1.0-0.8=0.2\). That is the dark grey line in figure 2.1, which indeed ends at height 0.2 on the right edge.

This model has two parameters, \(\bphi=[\phi_0,\phi_1]\). Prince writes them as a list in square brackets; think of it as a vector with two entries.

2.2.2 The least squares loss

Here is the training set of figure 2.2a: \(I=12\) points. These are the values in Prince's companion notebook 2.1; you will check in code that they reproduce the losses printed in figure 2.2 exactly.

\(i\)123456789101112
\(x_i\)0.030.190.340.460.780.811.081.181.391.601.651.90
\(y_i\)0.670.851.051.001.401.501.301.541.551.681.731.60

How do we turn twelve gaps into one number? Prince squares each gap and adds them up:

Equation 2.5 · least squares loss
\[\begin{aligned}L[\bphi]&=\sum_{i=1}^{I}\big(\mathrm{f}[x_i,\bphi]-y_i\big)^2\\&=\sum_{i=1}^{I}\big(\phi_0+\phi_1x_i-y_i\big)^2\end{aligned}\]

Read: "L of phi is the sum, over all I training points, of prediction minus truth, squared". For each point: predict, subtract the true value, square. Then add the twelve squares.

Why square? Two reasons you can see now. First, squaring makes every term positive, so a point above the line and a point below it cannot cancel each other out. Second, squaring punishes big errors much more than small ones: an error of 2 costs 4, an error of 0.5 costs only 0.25. Prince promises a deeper reason in Chapter 5: least squares is what you get when you assume the noise is Gaussian. (This is exactly the residual sum of squares, RSS, that ISLP minimises in simple linear regression.)

The individual gaps \(\mathrm{f}[x_i,\bphi]-y_i\) are called residuals or errors. The sum \(L\) is also called the training error or cost.

Worked example · the loss of the cyan line in figure 2.2b, by hand
\(\phi_0=0.4,\ \phi_1=0.2\). Compute \(L[\bphi]\) for the twelve points in the table.
  1. Predict for each point: \(\mathrm{f}[x_i,\bphi]=0.4+0.2x_i\). Point 1: \(0.4+0.2\times0.03=\mathbf{0.406}\). Point 12: \(0.4+0.2\times1.90=\mathbf{0.780}\).
  2. Subtract the truth to get each residual. Point 1: \(0.406-0.67=\mathbf{-0.264}\). Point 12: \(0.780-1.60=\mathbf{-0.820}\). All twelve residuals: \[-0.264,\ -0.412,\ -0.582,\ -0.508,\ -0.844,\ -0.938,\ -0.684,\ -0.904,\ -0.872,\ -0.960,\ -1.000,\ -0.820\]All negative: the cyan line lies below every point, exactly as the picture shows.
  3. Square each one: \(0.0697,\ 0.1697,\ 0.3387,\ 0.2581,\ 0.7123,\ 0.8798,\ 0.4679,\ 0.8172,\ 0.7604,\ 0.9216,\ 1.0000,\ 0.6724\).
  4. Add them: \(0.0697+0.1697+\dots+0.6724=\mathbf{7.068}\).
\(L[0.4,\ 0.2]=7.07\), exactly the value printed in figure 2.2b.

All twelve predictions in one matrix multiplication

Writing "for each point, predict" twelve times is tedious. Linear algebra (Vectors & matrices) packs it into one line. Put a column of ones next to the inputs; this is called the design matrix \(\bX\). Then every prediction is a row of \(\bX\) times the parameter vector:

Worked example · predictions and residuals as matrices (first four points)
\(\bphi=\begin{pmatrix}0.4\\0.2\end{pmatrix}\), points 1–4: \(x=0.03,0.19,0.34,0.46\); \(y=0.67,0.85,1.05,1.00\).
  1. Multiply each row by the column vector: first entry times \(\phi_0\), plus second entry times \(\phi_1\). \[\bX\bphi=\begin{pmatrix}1&0.03\\1&0.19\\1&0.34\\1&0.46\end{pmatrix}\begin{pmatrix}0.4\\0.2\end{pmatrix}\]\[=\begin{pmatrix}1(0.4)+0.03(0.2)\\1(0.4)+0.19(0.2)\\1(0.4)+0.34(0.2)\\1(0.4)+0.46(0.2)\end{pmatrix}\]\[=\begin{pmatrix}0.406\\0.438\\0.468\\0.492\end{pmatrix}\]The column of ones is there so that \(\phi_0\) gets added to every prediction.
  2. Subtract the targets to get the residual vector \(\mathbf{r}=\bX\bphi-\by\): \[\mathbf{r}=\begin{pmatrix}0.406\\0.438\\0.468\\0.492\end{pmatrix}-\begin{pmatrix}0.67\\0.85\\1.05\\1.00\end{pmatrix}\]\[=\begin{pmatrix}-0.264\\-0.412\\-0.582\\-0.508\end{pmatrix}\]
  3. The sum of squares is the vector times itself, \(\mathbf{r}^T\mathbf{r}\) ("r-transpose r"): \[\begin{aligned}\mathbf{r}^T\mathbf{r}&=(-0.264)^2+(-0.412)^2\\&\quad+(-0.582)^2+(-0.508)^2\\&=0.0697+0.1697\\&\quad+0.3387+0.2581\\&=0.8362\end{aligned}\]
For these four points the loss contribution is \(0.836\); with all twelve rows the same recipe gives \(L=7.068\).
The same loss, written with matrices
\[L[\bphi]=(\bX\bphi-\by)^T(\bX\bphi-\by)\]

Read: "residual vector, transposed, times residual vector": the sum of the squared residuals.

Let's reproduce all three of Prince's losses in code. First, the data. This setup cell rebuilds everything the lesson needs, so you can start here any time:

import numpy as np
import matplotlib.pyplot as plt
# Prince's training data (figure 2.2a, notebook 2.1)
x = np.array([0.03, 0.19, 0.34, 0.46, 0.78, 0.81, 1.08, 1.18, 1.39, 1.60, 1.65, 1.90])
y = np.array([0.67, 0.85, 1.05, 1.00, 1.40, 1.50, 1.30, 1.54, 1.55, 1.68, 1.73, 1.60])

def f(x, phi0, phi1):
    """The 1-D linear regression model, equation 2.4."""
    return phi0 + phi1 * x

def loss(phi0, phi1):
    """Least squares loss, equation 2.5."""
    return np.sum((f(x, phi0, phi1) - y) ** 2)

print("I =", len(x), "training pairs")
New Python: def f(x, phi0, phi1): makes a function, and the text in triple quotes is a docstring: a note saying what the function does. Because x is a NumPy array, phi0 + phi1 * x computes all twelve predictions at once (you met this "maths on whole arrays" in NumPy II).

Figure 2.2 shows three lines: (b) \(\bphi=[0.4,0.2]\), (c) \(\bphi=[1.6,-0.8]\), (d) \(\bphi=[0.82,0.52]\). Which has the smallest loss, and roughly how big is it?

  1. (b), because its slope is small
  2. (c), because it passes through the middle of the points
  3. (d), with a loss well below 1
(d) follows the trend of the points, so all twelve residuals are small (about ±0.1 to 0.2). Squares of numbers like 0.13 are about 0.017, and twelve of them add to about 0.2. Line (c) crosses the cloud but slopes the wrong way, so most points are far from it: crossing the middle is not the same as being close to every point.
lines = {"(b) cyan": (0.4, 0.2), "(c) grey": (1.6, -0.8), "(d) green": (0.82, 0.52)}
for name, (p0, p1) in lines.items():
    r = f(x, p0, p1) - y          # the twelve residuals
    print(f"{name:10s} L = {loss(p0, p1):6.3f}   biggest gap = {np.abs(r).max():.3f}")
Read the output: 7.068, 10.280 and 0.201, matching the figure. New Python: the dictionary lines maps names to pairs; .items() walks over (name, pair); (p0, p1) unpacks each pair into two variables. Inside an f-string, :6.3f means "3 decimals, 6 characters wide".

The loss is a function of the parameters: a surface

Here is the key change of viewpoint. Up to now the data varied and the line was fixed. Now freeze the data and let the parameters vary. Every choice of \((\phi_0,\phi_1)\) gives one number \(L\). Two inputs, one output: that is a surface over the \((\phi_0,\phi_1)\) plane, like a landscape. Good lines are low ground; bad lines are hills.

# Evaluate the loss on a grid of (phi0, phi1) values, like figure 2.3b
p0s = np.linspace(0, 2, 101)
p1s = np.linspace(-1, 1, 101)
P0, P1 = np.meshgrid(p0s, p1s)               # two 101x101 grids
Lgrid = np.array([[loss(a, b) for a in p0s] for b in p1s])
i, j = np.unravel_index(Lgrid.argmin(), Lgrid.shape)
print("lowest grid point: phi0 =", round(p0s[j], 2), " phi1 =", round(p1s[i], 2), " L =", round(Lgrid[i, j], 4))
fig, ax = plt.subplots(figsize=(5, 4.2))
ax.contourf(P0, P1, np.log(Lgrid), levels=30, cmap="copper")
ax.contour(P0, P1, Lgrid, levels=[0.3, 0.6, 1, 2, 4, 8, 16, 32], colors="w", linewidths=0.6)
ax.plot([0.4, 1.6, 0.82], [0.2, -0.8, 0.52], "o", color="c")
ax.invert_yaxis(); ax.set_xlabel("intercept phi0"); ax.set_ylabel("slope phi1")
plt.show()
Read the output: brute force over 10,201 grid points finds the lowest at \(\phi_0=0.82,\ \phi_1=0.52\), Prince's green line. New Python: np.meshgrid builds coordinate grids; the nested list comprehension computes one loss per grid point; argmin() finds the position of the smallest entry and np.unravel_index turns it into a (row, column) pair. We colour by \(\log L\) so the valley floor is visible, and invert_yaxis() makes the picture match the book.
Start from Prince's cyan line (b). Increase \(\phi_1\) slowly: the red residuals shrink, the loss falls and the dot on the right moves towards the green ring, the bottom of the valley (the contour ellipses are lines of equal loss; the colour gets stronger as the loss grows). Now press "Step downhill" a few times and watch the dot walk down the slope, as in figure 2.4. You can also click or drag on the heat map to choose \(\bphi\). The valley is a tilted ellipse: raising the slope can be partly compensated by lowering the intercept. (Here the slope axis points upwards; Prince draws it upside down.)

You have seen this bowl before. Least squares is the mathematics of the Wiener filter and the LMS adaptive equaliser. The mean-squared error is a quadratic function of the filter taps, so its surface is a bowl (an elliptic paraboloid); the optimum is where the gradient is zero (the Wiener–Hopf, or normal, equations); and LMS walks downhill on that bowl one step at a time. The tilt of the ellipses comes from correlation between the two "inputs" \(1\) and \(x\), just as correlated taps tilt the MSE surface. The step-size limit (too big and it diverges) is the same too; Prince returns to it in Chapter 6.

Training means finding the bottom of the bowl

Putting the loss into the training equation 2.3 gives the full statement of the problem:

Equation 2.6 · least squares training
\[\begin{aligned}\hat\bphi&=\argmin_{\bphi}\Big[\sum_{i=1}^{I}\big(\mathrm{f}[x_i,\bphi]-y_i\big)^2\Big]\\&=\argmin_{\bphi}\Big[\sum_{i=1}^{I}\big(\phi_0+\phi_1x_i-y_i\big)^2\Big]\end{aligned}\]

Read: "the best phi is the phi that makes the sum of squared errors smallest".

With only two parameters we can do it by brute force, as the grid cell did. With a million parameters (a small modern network), a grid with just 10 values per parameter would need \(10^{1{,}000{,}000}\) loss evaluations. We need something smarter.

2.2.3 Training: walking downhill

The method that scales is the one a hiker uses in fog. You cannot see the whole valley, but you can feel which way the ground slopes under your feet. So you

  1. start somewhere (random parameters),
  2. measure the slope of the loss surface where you stand: the gradient,
  3. take a small step in the steepest downhill direction,
  4. repeat until the ground is flat (the gradient is zero).

This is gradient descent. It needs the gradient: the two partial derivatives \(\partial L/\partial\phi_0\) ("partial L by partial phi-zero") and \(\partial L/\partial\phi_1\). If partial derivatives are new, they are taught in Derivatives & gradients; Problem 2.1 below derives these two step by step. The results are:

Gradient of the least squares loss (Problem 2.1)
\[\frac{\partial L}{\partial\phi_0}=\sum_{i=1}^{I}2(\phi_0+\phi_1x_i-y_i)\]\[\frac{\partial L}{\partial\phi_1}=\sum_{i=1}^{I}2x_i(\phi_0+\phi_1x_i-y_i)\]

Read: "the slope of L in the phi-zero direction is twice the sum of the residuals; in the phi-one direction it is twice the sum of each residual times its x".

Tiny example. At the cyan line \((0.4,\,0.2)\) the residuals were all negative and add up to \(-8.788\), so \(\partial L/\partial\phi_0=2\times(-8.788)=-17.58\). Negative means "increasing \(\phi_0\) lowers the loss": raise the line. That makes sense, because the line is below every point.

The step rule is: new parameters = old parameters minus (step size × gradient). With step size \(\alpha\) (alpha, also called the learning rate):

One gradient descent step
\[\begin{pmatrix}\phi_0\\\phi_1\end{pmatrix}\leftarrow\begin{pmatrix}\phi_0\\\phi_1\end{pmatrix}-\alpha\begin{pmatrix}\partial L/\partial\phi_0\\\partial L/\partial\phi_1\end{pmatrix}\]

Read: "replace phi by phi minus alpha times the gradient". The arrow \(\leftarrow\) means "overwrite with".

Worked example · one downhill step from the cyan line
Start at \(\bphi=(0.4,\ 0.2)\) with step size \(\alpha=0.02\). From the residuals above: \(\sum_i r_i=-8.788\) and \(\sum_i x_ir_i=-9.697\).
  1. Gradient: \(\partial L/\partial\phi_0=2\times(-8.788)=\mathbf{-17.576}\) and \(\partial L/\partial\phi_1=2\times(-9.697)=\mathbf{-19.395}\).
  2. Scale by \(\alpha\) and subtract, entry by entry: \[\begin{pmatrix}0.4\\0.2\end{pmatrix}-0.02\begin{pmatrix}-17.576\\-19.395\end{pmatrix}=\begin{pmatrix}0.4\\0.2\end{pmatrix}-\begin{pmatrix}-0.352\\-0.388\end{pmatrix}=\begin{pmatrix}0.752\\0.588\end{pmatrix}\]Subtracting a negative gradient moves both parameters up: the line rises and steepens.
  3. New loss: \(L[0.752,\ 0.588]\approx\mathbf{0.220}\), down from 7.068 in one step.
After one step: \(\bphi=(0.752,\ 0.588)\) and \(L\approx0.22\).
def grad(phi0, phi1):
    r = phi0 + phi1 * x - y                      # residuals
    return np.array([2 * r.sum(), 2 * (x * r).sum()])

phi = np.array([0.12, 0.10])                     # start near position 0 of figure 2.4
alpha = 0.02
for step in range(8):
    print(f"step {step}: phi = ({phi[0]:.3f}, {phi[1]:.3f})   L = {loss(*phi):.4f}")
    phi = phi - alpha * grad(*phi)
Read the output: the first step is a giant leap (the gradient is large far from the minimum), then progress slows as the ground flattens. New Python: loss(*phi) "unpacks" the two-element array into two arguments; it means the same as loss(phi[0], phi[1]). Try: change alpha to 0.05 and run again. The loss explodes: each step overshoots the valley and lands higher up the far side.

Gradient descent is not needed for a straight line. Prince's footnote: for linear regression you can solve for \(\hat\bphi\) exactly with algebra (Problem 2.2). We use the iterative method because it is the only method that works for neural networks, where there is no formula and far too many parameters to search a grid. Chapters 6 and 7 are about doing it well.

2.2.4 Testing, underfitting and overfitting

After training, the question is: how well will the model do in the real world? We answer it by computing the loss on separate test data. How well the model generalises depends on two things:

  • The data. Is the training set representative and complete? A Prius model trained only on cars from Chennai may fail on cars from Delhi.
  • How expressive the model is. A model that is too simple cannot capture the true relationship: underfitting. A model that is too flexible can describe quirks of this particular training sample that are not real: overfitting.

Our twelve points bend: they rise quickly, then level off. A straight line slightly underfits. A wildly flexible curve would overfit. We have no separate test set, so let's make one: hold out four of the twelve points (numbers 3, 6, 9 and 11), train on the other eight, and test on the four.

We train a straight line and a degree-7 polynomial on the 8 training points and test on the other 4. Which will be true?

  1. The polynomial wins on both training and test loss
  2. The polynomial wins on training loss, but loses badly on test loss
  3. The line wins on both
A degree-7 polynomial has 8 coefficients: just enough to pass through all 8 training points exactly, so its training loss is essentially 0. Between the training points it wiggles to hit every one, so it misses the test points by much more than the line does. That is overfitting in one picture.
test = np.array([2, 5, 8, 10])                   # positions of the held-out points (Python counts from 0)
train = np.setdiff1d(np.arange(12), test)        # the other 8
for deg in [1, 7]:
    coef = np.polyfit(x[train], y[train], deg)   # least squares fit of a polynomial
    L_tr = np.sum((np.polyval(coef, x[train]) - y[train]) ** 2)
    L_te = np.sum((np.polyval(coef, x[test]) - y[test]) ** 2)
    print(f"degree {deg}: training loss {L_tr:9.5f}   test loss {L_te:9.4f}")
xs = np.linspace(0, 2, 300)
plt.plot(x[train], y[train], "o", label="train"); plt.plot(x[test], y[test], "s", label="test")
for deg in [1, 7]:
    plt.plot(xs, np.polyval(np.polyfit(x[train], y[train], deg), xs), label=f"degree {deg}")
plt.ylim(0, 2.5); plt.legend(); plt.show()
Read the output: the line has a small training loss and a similar small test loss: it generalises. The degree-7 polynomial has a training loss of zero (it threads every training point) and a test loss about eight times larger than the line's. New Python: np.setdiff1d(a, b) keeps the entries of a that are not in b; np.polyfit(x, y, deg) fits a polynomial by least squares; np.polyval evaluates it at new inputs.
Degree 0 is a flat line: it underfits, so both losses are high. Move to degree 1 or 2: both losses are low. Now climb to 6 and 7: the training loss (circles) heads to zero while the test loss (squares, red gaps) grows. More parameters is not automatically better; what matters is the loss on data the model has not seen.

Interview classic: "Your training loss is tiny but your validation loss is large. What is happening and what do you do?" Answer: overfitting. Get more data, use a simpler model or regularisation (Prince Chapter 9), stop training earlier, or use data augmentation. The opposite pattern (both losses high) is underfitting: use a more expressive model, or train longer.

Notes from the end of the chapter

Loss versus cost. In most of the book, and in practice, "loss function" and "cost function" mean the same thing. Strictly, the loss is the term for one data point, \((\mathrm{f}[x_i,\bphi]-y_i)^2\), and the cost is the whole quantity being minimised, the sum, which may also contain extra terms not tied to any data point (regularisation, Chapter 9). An objective function is anything we maximise or minimise.

Discriminative versus generative. Our model predicts the output from the measurement, \(y=\mathrm{f}[x,\bphi]\): a discriminative model. The alternative is a generative model \(x=\mathrm{g}[y,\bphi]\), which describes how the measurement is produced from the quantity of interest. To predict, you must then invert it, \(y=\mathrm{g}^{-1}[x,\bphi]\), which can be hard. The advantage is that you can build in knowledge of how the data were made. Prince's example: to find the 3-D position and orientation \(y\) of a car in an image \(x\), you could build car shape, 3-D geometry and light transport into \(\mathrm{g}\). In practice, discriminative models trained on lots of data usually win. Problem 2.3 asks whether the two approaches give the same line.

Generative means a forward model of the channel. In communications you usually know the forward model: received signal = channel × transmitted symbol + noise, \(x=\mathrm{g}[y]\). Detection then inverts it (maximum-likelihood detection, zero-forcing equalisation). That is the generative route. A neural receiver trained end to end to map received samples straight to bits is the discriminative route.

def descend(x, y, phi_start, alpha, n_steps):
    phi = np.array(phi_start, dtype=float)
    for _ in range(n_steps):
        r = phi[0] + phi[1] * x - y

To walk "downhill" on the loss function (equation 2.5), we measure its gradient with respect to the parameters \(\phi_0\) and \(\phi_1\). Calculate expressions for the slopes \(\partial L/\partial\phi_0\) and \(\partial L/\partial\phi_1\).

Hint

The derivative of a sum is the sum of the derivatives. For one term \((\phi_0+\phi_1x_i-y_i)^2\), use the chain rule: the derivative of \(u^2\) is \(2u\), times the derivative of \(u\).

Final answer
\[\frac{\partial L}{\partial\phi_0}=2\sum_{i=1}^{I}(\phi_0+\phi_1x_i-y_i)\]\[\frac{\partial L}{\partial\phi_1}=2\sum_{i=1}^{I}x_i(\phi_0+\phi_1x_i-y_i)\]
Full solution, step by step
  1. Name the inside of one term: \(u_i=\phi_0+\phi_1x_i-y_i\) (the \(i\)-th residual). Then \(L=\sum_iu_i^2\).
  2. Differentiate the sum term by term: \(\dfrac{\partial L}{\partial\phi_0}=\sum_i\dfrac{\partial (u_i^2)}{\partial\phi_0}\).
  3. Chain rule: \(\dfrac{\partial(u_i^2)}{\partial\phi_0}=2u_i\cdot\dfrac{\partial u_i}{\partial\phi_0}\). In \(u_i=\phi_0+\phi_1x_i-y_i\) only the first term contains \(\phi_0\), with coefficient 1, so \(\partial u_i/\partial\phi_0=1\).A partial derivative treats every other symbol (\(\phi_1\), \(x_i\), \(y_i\)) as a constant.
  4. Hence \(\dfrac{\partial L}{\partial\phi_0}=\sum_i2u_i=2\sum_i(\phi_0+\phi_1x_i-y_i)\).
  5. Same for \(\phi_1\): in \(u_i\) the only term with \(\phi_1\) is \(\phi_1x_i\), so \(\partial u_i/\partial\phi_1=x_i\) and \(\dfrac{\partial L}{\partial\phi_1}=\sum_i2u_ix_i=2\sum_ix_i(\phi_0+\phi_1x_i-y_i)\).
  6. In matrix form (with the design matrix \(\bX\) from the lesson): \(\dfrac{\partial L}{\partial\bphi}=2\bX^T(\bX\bphi-\by)\). The first row of \(\bX^T\) is all ones (giving \(\sum r_i\)); the second row is the \(x_i\) (giving \(\sum x_ir_i\)).
  7. Numerical check at the cyan line \((0.4,\,0.2)\): \(-17.576\) and \(-19.395\), as in the worked example. The code compares the formula with finite differences.

Interpretation: \(\partial L/\partial\phi_0\) is twice the total residual. If the line is on average below the data (residuals negative), the gradient is negative and descent raises the intercept. \(\partial L/\partial\phi_1\) weights each residual by its \(x\): residuals far to the right matter most for the slope, which is why tilting the line is what fixes errors at large \(x\).

Hint

The generative loss measures errors in \(x\) (horizontal gaps); the discriminative loss measures errors in \(y\) (vertical gaps). Must they give the same line?

Final answer

Loss: \(L[\bphi]=\sum_i(\phi_0+\phi_1y_i-x_i)^2\). Inverse: \(y=(x-\phi_0)/\phi_1\). In general the predictions are different; the two agree only when the points lie exactly on a line (correlation \(\pm1\)). For the points \((0,0),(1,2),(2,1)\) the discriminative line is \(y=0.5+0.5x\), but the inverted generative model gives \(y=-1+2x\).

Full solution, step by step
  1. Loss. The model now predicts \(x\) from \(y\), so the mismatch is measured in \(x\): \(L[\bphi]=\sum_{i=1}^{I}(\mathrm{g}[y_i,\bphi]-x_i)^2=\sum_i(\phi_0+\phi_1y_i-x_i)^2\). Geometrically, it adds up squared horizontal distances from the points to the line.
  2. Inverse. Solve \(x=\phi_0+\phi_1y\) for \(y\): subtract \(\phi_0\), then divide by \(\phi_1\) (we need \(\phi_1\ne0\)): \(y=\mathrm{g}^{-1}[x,\bphi]=\dfrac{x-\phi_0}{\phi_1}\). As an ordinary line this has intercept \(-\phi_0/\phi_1\) and slope \(1/\phi_1\).
  3. Compare the slopes. Problem 2.2 with the roles of \(x\) and \(y\) swapped gives \(\hat\phi^{\,g}_1=\dfrac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(y_i-\bar y)^2}\), so the implied slope of \(y\) on \(x\) is \(1/\hat\phi^{\,g}_1=\dfrac{\sum(y_i-\bar y)^2}{\sum(x_i-\bar x)(y_i-\bar y)}\). The discriminative slope is \(\dfrac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}\). Divide the first by the second: \[\frac{\text{discrim. slope}}{\text{generative slope}}\]\[=\frac{\big(\sum(x_i-\bar x)(y_i-\bar y)\big)^2}{\sum(x_i-\bar x)^2\,\sum(y_i-\bar y)^2}=r^2,\] the squared correlation coefficient. So the two agree only if \(r^2=1\): all points exactly on a line.
  4. Three points \((0,0),(1,2),(2,1)\). Means: \(\bar x=1,\ \bar y=1\). Deviations: \(x\): \(-1,0,1\); \(y\): \(-1,1,0\). Sums: \(\sum dx\,dy=(-1)(-1)+0(1)+1(0)=1\), \(\sum dx^2=2\), \(\sum dy^2=2\).
  5. Discriminative: slope \(1/2=0.5\), intercept \(1-0.5\times1=0.5\), so \(y=0.5+0.5x\).
  6. Generative: \(\hat\phi_1=1/2\), \(\hat\phi_0=\bar x-0.5\bar y=0.5\), so \(x=0.5+0.5y\). Inverted: \(y=(x-0.5)/0.5=-1+2x\).
  7. At \(x=2\) the first predicts \(1.5\) and the second \(3\). Different. Both lines pass through the centre \((\bar x,\bar y)=(1,1)\); the discriminative one is flatter by the factor \(r^2=1/4\). This flattening is "regression towards the mean".

  3. That the result is rounded down
  4. That \(\bphi\) is a matrix
Prince reserves square brackets for function arguments so they are never confused with round brackets used for grouping. Nothing is multiplied, rounded, or assumed to be a matrix.

Which statement about the loss \(L[\bphi]\) is correct?

  1. It is a function of the input \(x\)
  2. It is large when the model fits well
  3. With the data fixed, it is a function of the parameters only
  4. It is the same thing as the prediction
The data are fixed during training, so the loss varies only with the parameters; that is why we can draw it as a surface over \((\phi_0,\phi_1)\). A small loss means a good fit. It is one number summarising all the predictions, not a prediction.

Two training points \((x,y)=(0,1)\) and \((1,1)\), line \(\phi_0=0.5,\ \phi_1=0\). What is the least squares loss?

Predictions 0.5 and 0.5; residuals \(-0.5\) and \(-0.5\); squares \(0.25+0.25=0.5\).

For the same two points and line, what is \(\partial L/\partial\phi_0\)?

\(2\sum r_i=2(-0.5-0.5)=-2\). Negative: raising \(\phi_0\) reduces the loss.

What does \(\argmin_{\bphi}L[\bphi]\) return?

  1. The parameter values at which \(L\) is smallest
  2. The smallest value of \(L\)
  3. The gradient of \(L\)
  4. The number of steps gradient descent takes
"arg" means "argument": the input that achieves the minimum. The smallest value itself is \(\min L\). The gradient and the number of steps are about how we search, not what we find.

A model has almost zero training loss and a large test loss. This is…

  1. underfitting
  2. a bug in the loss function
  3. a sign the model is too simple
  4. overfitting
It describes the training data, quirks included, too well and fails to generalise. Underfitting (a model that is too simple) shows up as a high training loss too. Nothing here points to a bug.

Why does deep learning use gradient descent even though linear regression has a closed-form solution?

  1. Gradient descent finds a lower loss than the closed form
  2. For neural networks, "gradient = 0" gives nonlinear equations with no formula, and grids are impossible with many parameters
  3. The closed form is only approximate
For the line, the closed form is exact, and gradient descent can at best match it. Networks have no closed form, so iteration is the only option.

In your own words: what is the difference between a model and its parameters? Use the Prius example.

The model is the form of the equation: a whole family of possible price rules, for example "price is a linear function of age and mileage". The parameters are the particular numbers in it (rupees per year of age, rupees per km, base price). We choose the model beforehand; training chooses the parameters from data.
Prince's general supervised model
\(\by=\mathrm{f}[\bx,\bphi]\): input \(\bx\), parameters \(\bphi\), output \(\by\).
What is inference?
Computing the prediction \(\by\) from an input \(\bx\) by running it through the model.
Least squares loss for the 1-D line
\(L[\bphi]=\sum_{i=1}^I(\phi_0+\phi_1x_i-y_i)^2\)
Training, as an equation
\(\hat\bphi=\argmin_{\bphi}L[\bphi]\)
\(\partial L/\partial\phi_0\) and \(\partial L/\partial\phi_1\) for the line
\(2\sum_i r_i\) and \(2\sum_i x_ir_i\), with residual \(r_i=\phi_0+\phi_1x_i-y_i\).
Normal equations for the line (matrix form)
\(\bX^T\bX\bphi=\bX^T\by\), i.e. \(\begin{pmatrix}I&\sum x_i\\\sum x_i&\sum x_i^2\end{pmatrix}\bphi=\begin{pmatrix}\sum y_i\\\sum x_iy_i\end{pmatrix}\).
Closed-form slope of the least squares line
\(\hat\phi_1=\dfrac{I\sum x_iy_i-\sum x_i\sum y_i}{I\sum x_i^2-(\sum x_i)^2}\), and \(\hat\phi_0=\bar y-\hat\phi_1\bar x\).
One gradient descent step
\(\bphi\leftarrow\bphi-\alpha\,\partial L/\partial\bphi\), with step size (learning rate) \(\alpha\).
Underfitting vs overfitting
Underfitting: model too simple, high training and test loss. Overfitting: fits training quirks, low training loss, high test loss.
Discriminative vs generative model
Discriminative: \(y=\mathrm{f}[x,\bphi]\) predicts the output directly. Generative: \(x=\mathrm{g}[y,\bphi]\) must be inverted to predict.
Loss vs cost (strict meaning)
Loss: the term for one data point. Cost: the whole quantity minimised (sum of losses plus any extra terms).
Shape of the least squares loss surface for a line
A bowl (quadratic) with tilted elliptical contours and a single minimum.
