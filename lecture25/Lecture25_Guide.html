A · Lecture 25 in 10 minutes

Lectures 23 and 24 were about DC: which output voltage you get for each input voltage (the VTC). They never asked how long it takes. Lecture 25 asks exactly that: when the input switches, how long until the output follows?

  1. The output is a capacitor. Wires, transistor junctions and the next gate all connect to $V_{out}$, so $V_{out}$ is the voltage on a capacitor $C_{load}$. A capacitor's voltage cannot jump. To change it, you must move charge $Q = C\,V$, and that takes time.
  2. Only one transistor works at a time. Input goes up → PMOS off, NMOS on → NMOS pulls charge out → output falls. Input goes down → NMOS off, PMOS on → PMOS pushes charge in → output rises.
  3. The one equation: time = charge to move ÷ current. $$\tau \approx \frac{C\,\Delta V}{I}$$ Bigger bucket ($C$) → slower. Bigger tap ($I$, so bigger $k$ or $V_{DD}$) → faster. Every question in this lecture is "find $C$" or "find $I$" or both.
  4. What we measure. Delay $\tau_{PHL}$ (output going High→Low) and $\tau_{PLH}$ (Low→High) are measured from the input's 50% point to the output's 50% point. So the output only has to travel half way: $\Delta V = V_{DD}/2$. The average delay is $\tau_P = (\tau_{PHL}+\tau_{PLH})/2$.
  5. The difficulty. The current $I$ is not constant. As the output falls, the NMOS starts in saturation (constant current), then goes linear (current shrinks). So "$C\Delta V/I$" has no single $I$.
  6. Two ways around it. Method 1 (average current): work out $I$ at the start and at the 50% point, average them, then use $C\Delta V/I_{avg}$. Method 2 (exact): integrate $C\,dV/dt = -I$ in two pieces. The result is one formula you can plug numbers into.
  7. What the formula tells you. $\tau \propto C/k$. Make the PMOS about 2.5× wider than the NMOS and rise = fall (that is the symmetric inverter of Lecture 24).
  8. Two extras. A loop of an odd number $N$ of inverters oscillates with $f = 1/(2N\tau_P)$. Every full switch costs energy $C V_{DD}^2$, so power is $P = C V_{DD}^2 f$.
The one sentence to remember "A gate is slow because its output is a bucket and its transistors are a tap." Delay = water ÷ flow = $C\Delta V / I$. Everything else is detail about finding $C$ and finding $I$.
What you already know (from Lectures 23–24) that we reuse $k_n = \mu_n C_{ox}(W/L)_n$, $k_p = \mu_p C_{ox}(W/L)_p$. With overdrive $u = |V_{GS}| - |V_T|$ and $v = |V_{DS}|$: $$\text{saturation } (v \ge u):\; I = \tfrac{k}{2}u^2 \qquad\qquad \text{linear } (v < u):\; I = \tfrac{k}{2}\big[2uv - v^2\big]$$ That is all the device physics Lecture 25 needs.

B1 · Where the capacitor comes from

A capacitor is just two conductors with an insulator between them. Nobody solders capacitors into a chip. They appear by themselves wherever this shape exists. Around the output of an inverter there are six of them.

The load capacitance (write this first in every delay question) $$C_{load} = \underbrace{C_{gd,n} + C_{gd,p}}_{\text{overlaps}} + \underbrace{C_{db,n} + C_{db,p}}_{\text{drain junctions}} + \underbrace{C_{int}}_{\text{wire}} + \underbrace{C_g}_{\text{next gate}}$$

② Forgetting the next stage's gate $C_g$. It is usually the largest term.

Only if the question asks "why" (theory from the lecture) The gate–channel part of the capacitance depends on the region. Off: $C_{GS}=C_{GD}=$ overlap only. Linear: each gets $\tfrac12 WLC_{ox}$ + overlap. Saturation: $C_{GS} = \tfrac23 WLC_{ox}$ + overlap, but $C_{GD}$ = overlap only, because the channel is pinched off at the drain. For $C_{load}$ the lecture keeps it simple: overlap for $C_{gd}$, full $WLC_{ox}$ for the next gate. More reverse bias → wider depletion → smaller $C_j$. "Zero-bias" in a question means: just use the given $C_{j}$.

B2 · What happens when the input switches

Put all those capacitors together into one $C_{load}$. Now Kirchhoff's current law at the output node gives the only equation of the lecture:

$$C_{load}\,\frac{dV_{out}}{dt} = i_{D,p} - i_{D,n}\qquad\text{(current in from PMOS minus current out through NMOS)}$$

With a sudden (step) input, only one transistor is on, so one of the two currents is zero.

The key question: which region is the working transistor in?

Take the falling output. The NMOS has $V_{GS} = V_{DD}$, so its overdrive is $u = V_{DD} - V_{T,n}$, a constant. Its $V_{DS} = V_{out}$, which falls. The saturation test is $V_{DS} \ge u$:

  • At the start $V_{out} = V_{DD}$, which is bigger than $V_{DD} - V_T$ → saturated. Current is constant $\tfrac{k}{2}u^2$.
  • When $V_{out}$ drops below $V_{DD} - V_T$ → linear. Current gets smaller as $V_{out}$ falls.
  • At the 50% point $V_{out} = V_{DD}/2$. This is below $V_{DD}-V_T$ whenever $V_T < V_{DD}/2$ (always, in normal inverters) → linear.
Intuition The rise is the same story with the PMOS: $|V_{DS,p}| = V_{DD} - V_{out}$. It starts saturated (output near 0), and goes linear once the output has risen by $|V_{T,p}|$. So both edges = "saturated for the first $V_T$ volts, then linear".

B4 · Method 1: the average-current method

The idea: the current changes during the fall, but not by much. So pretend it is constant at the average of its value at the start and its value at the 50% point. Then the bucket formula works directly:

$$\tau_{PHL} = \frac{C_{load}\,(V_{DD}/2)}{I_{avg}},\qquad I_{avg} = \frac{I(\text{start}) + I(\text{50\% point})}{2}$$
The recipe: 4 steps, every time
  1. Overdrive of the working transistor: $u = V_{DD} - |V_T|$.
  2. Start point ($|V_{DS}| = V_{DD}$, saturated): $I_1 = \frac{k}{2}u^2$.
  3. 50% point ($|V_{DS}| = V_{DD}/2$, linear): $I_2 = \frac{k}{2}\big[2u\,\tfrac{V_{DD}}{2} - (\tfrac{V_{DD}}{2})^2\big]$.
  4. $I_{avg} = (I_1+I_2)/2$, then $\tau = C\,(V_{DD}/2)/I_{avg}$.
Mistake number 1 in this lecture Using the saturation formula at both ends. At the 50% point the transistor is linear. Check: is $V_{DD}/2 < V_{DD} - |V_T|$? Yes whenever $|V_T| < V_{DD}/2$.

This method is always a few percent too slow (≈ 4% in Example 25.2), because the real current curve bulges above the straight average. Use it when the question says "average current", or as a quick check.

B5 · Method 2: the exact formula

Here we do the integral properly. You need the result in the exam. Read the derivation once so the formula makes sense.

Step 1: separate the variables

For the fall, only the NMOS works: $C\,\dfrac{dV}{dt} = -I(V)$, so $dt = -\dfrac{C\,dV}{I(V)}$. Time = add up (integrate) $C\,dV/I$ over the voltage range. That is the bucket formula, done in thin slices.

Step 2: segment 1, saturated, from $V_{DD}$ down to $V_{DD}-V_T$

The current is constant, so no integral is needed. The output drops by exactly $V_T$:

$$t_{sat} = \frac{C\cdot V_T}{\tfrac{k}{2}u^2} = \frac{2C\,V_T}{k\,u^2}$$

Step 3: segment 2, linear, from $u$ down to $V_{DD}/2$

Now $I = \tfrac{k}{2}V(2u - V)$. One standard integral (partial fractions):

$$\int\frac{dV}{V(2u-V)} = \frac{1}{2u}\ln\frac{V}{2u-V}$$

Put in the limits $V = u$ (start, where the log is $\ln 1 = 0$) and $V = V_{DD}/2$ (end):

$$t_{lin} = \frac{C}{k\,u}\,\ln\!\left(\frac{2u}{V_{DD}/2} - 1\right) = \frac{C}{k\,u}\,\ln\!\left(\frac{4u}{V_{DD}} - 1\right)$$

Step 4: add them

Memorise: exact delay of a CMOS inverter (step input) $$\boxed{\;\tau = \frac{C_{load}}{k\,u}\left[\frac{2|V_T|}{u} + \ln\!\left(\frac{4u}{V_{DD}} - 1\right)\right],\qquad u = V_{DD} - |V_T|\;}$$ $\tau_{PHL}$: use $k_n$ and $V_{T,n}$.    $\tau_{PLH}$: use $k_p$ and $|V_{T,p}|$.
Say it out loud "C over k-u, times [sat bit + log bit]."  Sat bit = $2V_T/u$ (the straight-line part). Log bit = $\ln(4u/V_{DD} - 1)$ (the curved part). The front factor $C/(ku)$ is an $RC$ time constant, because a linear MOSFET near $V_{DS}=0$ is a resistor $R_{on} = 1/(ku)$.
Your lecture writes it with V_OH and V_OL $$\tau_{PHL} = \frac{C_{load}}{k_n(V_{OH}-V_{T0,n})}\left[\frac{2V_{T0,n}}{V_{OH}-V_{T0,n}} + \ln\!\left(\frac{4(V_{OH}-V_{T0,n})}{V_{OH}+V_{OL}}-1\right)\right]$$ For CMOS, $V_{OH} = V_{DD}$ and $V_{OL} = 0$, and it becomes the boxed formula. Same thing.
Rare case: if |V_T| ≥ V_DD/2 Then the transistor is still saturated at the 50% point, so there is no linear segment. The whole half-swing is constant current: $\tau = \dfrac{C\,(V_{DD}/2)}{\tfrac{k}{2}u^2} = \dfrac{C\,V_{DD}}{k\,u^2}$. (This is the second line of your formula sheet's $D(k,T)$.)

B6 · Rise and fall time (10% ↔ 90%)

Same integral, different limits: the fall time runs from $0.9V_{DD}$ down to $0.1V_{DD}$, not from $V_{DD}$ to $V_{DD}/2$.

  • Saturated piece: from $0.9V_{DD}$ down to $u$. Only exists if $0.9V_{DD} > u$, i.e. $|V_T| > 0.1V_{DD}$ (normal case). It lasts $\dfrac{C(0.9V_{DD} - u)}{\tfrac{k}{2}u^2} = \dfrac{C}{ku}\cdot\dfrac{2(|V_T| - 0.1V_{DD})}{u}$.
  • Linear piece: from $u$ down to $0.1V_{DD}$: $\dfrac{C}{ku}\ln\!\left(\dfrac{2u}{0.1V_{DD}} - 1\right) = \dfrac{C}{ku}\ln\!\left(\dfrac{20u}{V_{DD}}-1\right)$.
Fall time (and rise time with the PMOS values) $$t_{fall} = \frac{C}{k\,u}\left[\frac{2(|V_T| - 0.1V_{DD})}{u} + \ln\!\left(\frac{20u}{V_{DD}} - 1\right)\right]$$ Same shape as the delay formula. Only the numbers inside change: $V_T \to V_T - 0.1V_{DD}$ and $4 \to 20$.

B7 · One MOSFET + one capacitor (Razavi-type questions)

Sometimes there is no inverter: just one NMOS charging or discharging a capacitor from some starting voltage. The method is the same as B5, but you must decide the region yourself, and the limits are whatever the question gives.

General recipe
  1. Write $V_{GS}$ and $V_{DS}$ in terms of the capacitor voltage $V_X$. (Which terminal is the capacitor on?)
  2. Find the overdrive $u = V_{GS} - V_T$ and check the region: saturated if $V_{DS} \ge u$.
  3. Write $C\,dV_X/dt = \pm I$ and separate: $dt = C\,dV_X / I$.
  4. Integrate between the start and end voltages. If the region changes on the way, split at the boundary.
SituationRegionTime from $V_i$ to $V_f$
Cap on drain, gate fixed, $V_{DS}=V_X \ge u$saturated$\dfrac{C\,(V_i - V_f)}{\tfrac{k}{2}u^2}$ (straight line)
Cap on drain, gate fixed, $V_X < u$ the whole timelinear$\dfrac{C}{k\,u}\ln\dfrac{V_i\,(2u - V_f)}{V_f\,(2u - V_i)}$
Cap on source (follower), $V_{GS} = V_G - V_X$saturated always (drain at $V_{DD}$)$\dfrac{2C}{k}\left[\dfrac{1}{V_G - V_T - V_f} - \dfrac{1}{V_G - V_T - V_i}\right]$

The follower slows down as it gets close to $V_G - V_T$, because its overdrive is shrinking to zero. It never quite gets there.

B8 · Design: what makes the gate faster

Every delay formula has the shape $\tau \propto \dfrac{C_{load}}{k\,(V_{DD} - |V_T|)}$. So there are three knobs:

KnobEffectCatch
smaller $C_{load}$τ goes down in proportionshorter wires, fewer gates driven
bigger $k$ (wider $W/L$)more current, τ ∝ 1/ka wider transistor has a bigger drain $C_{db}$, and a bigger gate that slows the previous stage
bigger $V_{DD}$more currentpower $\propto V_{DD}^2$ goes up
Two design rules you will use Rule 1 (scaling): with $C$ and voltages fixed, $\tau \propto 1/k$. To change a delay by a factor, change $k$ (so $W/L$) by the inverse factor.
Rule 2 (equal edges): $\tau_{PHL} = \tau_{PLH}$ needs $k_p = k_n$ (if $|V_{T,p}| = V_{T,n}$). Since $\mu_n \approx 2.5\mu_p$, that means $(W/L)_p \approx 2.5\,(W/L)_n$. That is exactly the symmetric inverter of Lecture 24 ($V_{th} = V_{DD}/2$, equal noise margins). So "sized for equal rise and fall delays" means "symmetric".

B9 · Ring oscillator and dynamic power

Ring oscillator

Ring oscillator $$T = 2N\tau_P,\qquad f = \frac{1}{2N\tau_P},\qquad N\text{ odd}$$ Used backwards to measure $\tau_P$: measure $f$, then $\tau_P = \dfrac{1}{2Nf}$.

Dynamic power

Memorise $$E_{cycle} = C_{load}V_{DD}^2,\qquad P_{dyn} = C_{load}V_{DD}^2 f,\qquad E_{PMOS} = E_{NMOS} = \tfrac12 C_{load}V_{DD}^2$$ Static power ≈ 0 in CMOS, because one transistor is always off when the output is steady.
Unit shortcut that saves calculator errors fF × V ÷ µA = ns  and  fF × V ÷ mA = ps. Put $C$ in fF, $k$ in µA/V², $I$ in µA and the delay comes out in ns directly. Example: $\dfrac{300\text{ fF}}{200\,\mu\text{A/V}^2 \times 2.7\text{ V}} = 0.556$ ns.
Calculator: use ln, not log. Type the bracket in one line, e.g. 1.2÷2.7+ln(10.8÷3.3−1) → 1.2654.

B10 · What Lecture 26 adds

Most of Lecture 26 repeats the Lecture 25 derivation, this time written out in full for $\tau_{PLH}$ as well. Three things are new or stated more clearly.

1 · The PLH formula, written out

$$\tau_{PLH} = \frac{C_{load}}{k_p(V_{DD}-|V_{T0,p}|)}\left[\frac{2|V_{T0,p}|}{V_{DD}-|V_{T0,p}|} + \ln\!\left(\frac{4(V_{DD}-|V_{T0,p}|)}{V_{DD}} - 1\right)\right]$$

This is the boxed formula of B5 with the PMOS numbers. The PMOS stays saturated while $V_{out} < |V_{T0,p}|$, then goes linear. It is the mirror image of the NMOS story.

2 · Equal delays

Condition for τPHL = τPLH $$k_n = k_p \quad\text{and}\quad V_{T0,n} = |V_{T0,p}|$$ Same $k$ and same threshold give the same formula, so the same delay. This is the symmetric inverter.

3 · A real input is not a perfect step

Delay with a slow input (Lecture 26) $$\tau_{PHL}(\text{actual}) = \sqrt{\tau_{PHL}^2(\text{step input}) + \left(\frac{\tau_r}{2}\right)^2}\qquad \tau_{PLH}(\text{actual}) = \sqrt{\tau_{PLH}^2(\text{step input}) + \left(\frac{\tau_f}{2}\right)^2}$$ $\tau_r$ is the input's rise time (the input rising makes the output fall: PHL). $\tau_f$ is the input's fall time.

Example: the inverter of Q3 ($\tau_{PHL} = 0.703$ ns) gets an input with $\tau_r = 0.5$ ns: $\sqrt{0.703^2 + 0.25^2} = \sqrt{0.4942 + 0.0625} = 0.746$ ns. That is a little slower than with a perfect step.

4 · Ring oscillator

The lecture ends with three inverters in a loop, each driving a capacitor ($C_1, C_2, C_3$). That is the ring oscillator of B9: $f = 1/(2N\tau_P)$ with $N = 3$.

T8 · Q1 · Noise margins of a non-symmetric inverter

$V_{DD} = 3.3$ V, $V_{T0,n} = 0.6$ V, $V_{T0,p} = -0.7$ V, $k_n = 200$, $k_p = 80$ µA/V². Find the noise margins. ($k_R = 2.5$, not symmetric.)

In plain words
"How much noise can sit on a logic 0 or a logic 1 before the next gate gets confused?" We need $V_{IL}$ and $V_{IH}$, the two slope = −1 points of the VTC (Fig. R.1).
Theory
Refresher R. At $V_{IL}$ use ① + ②. At $V_{IH}$ use ③ + ④. Not symmetric, so the shortcut $(3V_{DD}+2V_T)/8$ is not allowed.
Plan
Write ② and ④ with numbers → substitute → solve two quadratics → back-substitute.
Solve
VIL (NMOS sat, PMOS linear)
  1. ②: $V_{IL} = \dfrac{2V_{out} - 0.7 - 3.3 + 2.5(0.6)}{3.5} = \dfrac{2V_{out} - 2.5}{3.5}$
  2. Put it into ①: $2.5(V_{in} - 0.6)^2 = 2(V_{in} - 2.6)(V_{out} - 3.3) - (V_{out} - 3.3)^2$. Expanding gives $V_{out}^2 + 0.0667\,V_{out} - 9.898 = 0$.
  3. Positive root: $V_{out} = 3.113$ V (high, as expected).
  4. $V_{IL} = (2 \times 3.113 - 2.5)/3.5 =$ 1.064 V
VIH (NMOS linear, PMOS sat)
  1. ④: $V_{IH} = \dfrac{3.3 - 0.7 + 2.5(2V_{out} + 0.6)}{3.5} = \dfrac{4.1 + 5V_{out}}{3.5}$
  2. Put it into ③: $2.5[2(V_{in} - 0.6)V_{out} - V_{out}^2] = (V_{in} - 2.6)^2$. This gives $V_{out}^2 + 2.667\,V_{out} - 0.7843 = 0$.
  3. Positive root: $V_{out} = 0.2673$ V (low, as expected).
  4. $V_{IH} = (4.1 + 5 \times 0.2673)/3.5 =$ 1.553 V
Noise margins: $NM_L = V_{IL} - 0 =$ 1.06 V   $NM_H = 3.3 - 1.553 =$ 1.75 V
Check
Regions: at $V_{IL}$, NMOS $V_{DS} = 3.11 \ge 1.064 - 0.6$ ✓ sat; PMOS $|V_{DS}| = 0.19 < 3.3 - 1.064 - 0.7$ ✓ linear. $NM_L < NM_H$ because the strong NMOS ($k_R = 2.5$) pulls the switching point left ✓. I also swept the VTC numerically: slope −1 at 1.064 V and 1.553 V ✓.

T8 · Q2 · Noise margins and Vth from µCox and W/L

nMOS: $V_{T0,n} = 0.6$ V, $\mu_nC_{ox} = 60$ µA/V², $(W/L)_n = 8$. pMOS: $V_{T0,p} = -0.7$ V, $\mu_pC_{ox} = 25$ µA/V², $(W/L)_p = 12$. $V_{DD} = 3.3$ V. Find the noise margins and $V_{th}$.

In plain words
Same job as Q1, but first build $k_n$ and $k_p$ yourself.
Theory
$k = \mu C_{ox}(W/L)$, then refresher R: ①–④ and the $V_{th}$ formula.
Plan
$k_n = 60 \times 8 = 480$, $k_p = 25 \times 12 = 300$ µA/V² → $k_R = 1.6$. Then exactly as Q1.

  2. $V_{IL} = \dfrac{2V_{out} - 4 + 0.96}{2.6} = \dfrac{2V_{out} - 3.04}{2.6}$ → into ①: $V_{out}^2 + 4.067V_{out} - 21.99 = 0$ → $V_{out} = 3.078$ V → $V_{IL} =$ 1.198 V
  3. $V_{IH} = \dfrac{2.6 + 1.6(2V_{out} + 0.6)}{2.6} = \dfrac{3.56 + 3.2V_{out}}{2.6}$ → into ③: $V_{out}^2 + 6.667V_{out} - 1.839 = 0$ → $V_{out} = 0.2653$ V → $V_{IH} =$ 1.696 V

T8 · Q3 · Design for Vth = 1.4 V, then process variation

T8 · Q4 · Inverter with an NMOS feedback switch

The inverter of Q3 has an NMOS M3 (W/L = 2/0.8, gate at 3.3 V) connected from its output back to its input. (a) Find $V_{out}$. (b) Does the $V_{T0,n}$ variation of M3 change $V_{out}$? (c) Find the supply current and its variation.

In plain words
We tie the inverter's output to its own input through a switch. The inverter wants to make the output the "opposite" of the input, but they are now the same wire. The only place where "output = input" is allowed is the middle point $V_{th}$.
Theory
Two facts. ① A MOSFET gate draws no DC current, so nothing flows through M3. A transistor that is on but carries no current has $V_{DS} = 0$, so $V_{in} = V_{out}$. ② On the VTC, $V_{out} = V_{in}$ happens only at $V_{th}$, where both transistors are saturated (Lecture 24).
Solve
  1. (a) $V_{out} = V_{in} = V_{th} =$ 1.4 V
  2. (b) No. M3 carries no current, so it drops no voltage, whatever its threshold. It only has to stay on: $V_{GS,3} = 3.3 - 1.4 = 1.9$ V, which is above even $0.69$ V ✓. (The inverter's own threshold variation does move $V_{out}$, through $V_{th}$: 1.29 V to 1.51 V as in Q3.)
  3. (c) At $V_{th}$ both transistors are saturated and carry the same current from $V_{DD}$ to ground: $I = \dfrac{\mu_nC_{ox}}{2}\dfrac{W_n}{L}(V_{th} - V_{T0,n})^2 = \dfrac{60}{2}\cdot\dfrac{W_n}{0.8}(0.8)^2 = 24\,W_n$ µA (with $W_n$ in µm).
  4. Variation: put each corner of Q3(b) in. Lowest: $V_{T0,n} = 0.69$, $V_{T0,p} = -0.84$ → $V_{th} = 1.398$ V → $18.8\,W_n$ µA. Highest: $V_{T0,n} = 0.51$, $V_{T0,p} = -0.56$ → $V_{th} = 1.402$ V → $29.8\,W_n$ µA. So the current changes by about −22 % to +24 %.
  5. Example: if $W_p = 2$ µm then $W_n = 1.875$ µm and $I \approx$ 45 µA (range 35 µA to 56 µA).
Note
The tutorial does not give the actual widths, only the ratio from Q3. So the current can only be given per µm of $W_n$, or for a width you choose. Say this in your answer.

T9 · Q1 · Fall time by both methods

$V_{DD} = 5$ V, $C_{load} = 1$ pF, $\mu_nC_{ox} = 20$ µA/V², $(W/L)_n = 10$, $V_{Tn} = 1$ V. Find $\tau_{fall}$ from $V_{out} = 4.5$ V to $0.5$ V by the average-current method and by the differential-equation method.

In plain words
The input jumps high. The NMOS empties a 1 pF bucket. How long does the water level take to go from 4.5 V down to 0.5 V?
Theory
B6 (rise/fall time) and B7 (integrate in pieces). The same as the delay, but the limits are 90 % and 10 %, not 100 % and 50 %.
Plan
$k_n = 20 \times 10 = 200$ µA/V². Overdrive $u = 5 - 1 = 4$ V. The NMOS is saturated while $V_{out} \ge 4$ V, linear below. So 4.5 → 4 V is saturated and 4 → 0.5 V is linear. $C = 1000$ fF.
Solve
Average-current method
  1. At 4.5 V ($V_{DS} = 4.5 \ge 4$, sat): $I_1 = 100 \times 4^2 = 1600$ µA.
  2. At 0.5 V (linear): $I_2 = 100\,[2(4)(0.5) - 0.5^2] = 100 \times 3.75 = 375$ µA.
  3. $I_{avg} = (1600 + 375)/2 = 987.5$ µA.
  4. $\tau_{fall} = \dfrac{1000\text{ fF} \times (4.5 - 0.5)\text{ V}}{987.5\text{ µA}} =$ 4.05 ns
Differential-equation method
  1. Saturated piece, 4.5 → 4 V (constant current 1600 µA): $\dfrac{1000 \times 0.5}{1600} = 0.3125$ ns.
  2. Linear piece, 4 → 0.5 V: $\dfrac{C}{ku}\ln\dfrac{V_i(2u - V_f)}{V_f(2u - V_i)} = \dfrac{1000}{200 \times 4}\ln\dfrac{4 \times 7.5}{0.5 \times 4} = 1.25 \times \ln 15 = 1.25 \times 2.708 = 3.385$ ns.
  3. $\tau_{fall} = 0.3125 + 3.385 =$ 3.70 ns
Check
The B6 one-line formula gives the same: $1.25[2(1 - 0.5)/4 + \ln(20 \times 4/5 - 1)] = 1.25 \times 2.958 = 3.70$ ns ✓. The average method is 10 % too slow here, much worse than for the delay, because the current changes a lot (1600 → 375 µA) over this long swing.

T9 · Q3 · Design an inverter for Vth and three timing specs

In plain words
Four rules, two unknowns. The $V_{th}$ rule fixes the ratio of the widths. The timing rules each say "the NMOS (or PMOS) must be at least this strong". Find the smallest sizes that obey every rule.
Theory
Refresher R (backwards $V_{th}$ → $k_R$). B5 exact delay, solved for $k$. B7 linear-only integral for the 2 V → 0.5 V fall.
Plan
① $k_R$ from $V_{th}$. ② Minimum $k_n$ from each timing rule. ③ The biggest minimum wins. ④ $k$ → $W$.
Solve
  1. $k_R = \left(\dfrac{3 - 1 - 1.5}{1.5 - 0.8}\right)^2 = \left(\dfrac{0.5}{0.7}\right)^2 = 0.510$. So $k_p = k_n/0.510 = 1.96\,k_n$.
  2. $\tau_{PHL} \le 0.2$ ns: $u_n = 2.2$, bracket $= \frac{1.6}{2.2} + \ln(\frac{8.8}{3} - 1) = 0.727 + 0.659 = 1.387$. $k_n \ge \dfrac{300}{0.2 \times 2.2} \times 1.387 = 945$ µA/V².
  3. $\tau_{PLH} \le 0.15$ ns: $u_p = 2$, bracket $= \frac{2}{2} + \ln(\frac{8}{3} - 1) = 1 + 0.511 = 1.511$. $k_p \ge \dfrac{300}{0.15 \times 2} \times 1.511 = 1511$ µA/V², so $k_n \ge 1511 \times 0.510 = 771$ µA/V².
  4. Fall 2 V → 0.5 V: $2 < u_n = 2.2$, so linear the whole way. $t = \dfrac{C}{k_n u}\ln\dfrac{2(4.4 - 0.5)}{0.5(4.4 - 2)} = \dfrac{300}{2.2\,k_n}\ln 6.5 \le 0.35$ ns → $k_n \ge 729$ µA/V².
  5. Strictest: $k_n \ge 945$ µA/V² (Fig. T9.3). Then $k_p = 945/0.510 = 1853$ µA/V².
  6. $W_n = \dfrac{k_n L}{\mu_nC_{ox}} = \dfrac{945 \times 0.6}{120} = 4.73$ µm; $W_p = \dfrac{1853 \times 0.6}{60} = 18.5$ µm. Round up: Wn ≈ 4.8 µm, Wp ≈ 18.8 µm
Check
With 4.8 / 18.8 µm: $\tau_{PHL} = 0.197$ ns ✓, $\tau_{PLH} = 0.121$ ns ✓, 2 → 0.5 V in 0.266 ns ✓, $V_{th} = 1.500$ V ✓. Both widths are above $W_{min} = 1.2$ µm ✓.

T9 · Q4 · Design for Vth = 2.2 V and τrise = 5 ns; then lower VDD

In plain words
The rise time is set by the PMOS alone, so it fixes $W_p$. The $V_{th}$ rule then fixes $W_n$ through the ratio.
Theory
B6 rise-time formula (10 % → 90 %, PMOS numbers). Refresher R for $k_R$. B5 for the delays.
Solve
  1. PMOS: $u = 5 - 1 = 4$ V, $0.1V_{DD} = 0.5$ V. Bracket $= \dfrac{2(1 - 0.5)}{4} + \ln\!\left(\dfrac{20 \times 4}{5} - 1\right) = 0.25 + \ln 15 = 2.958$.
  2. $\tau_{rise} = \dfrac{2000}{k_p \times 4} \times 2.958 = 5$ ns → $k_p = 295.8$ µA/V² → $W_p = 295.8/20 =$ 14.8 µm

  4. (b) $\tau_{PHL} = \dfrac{2000}{489 \times 4.2}\Big[\dfrac{1.6}{4.2} + \ln(3.36 - 1)\Big] = 0.974 \times 1.240 = 1.21$ ns.
    $\tau_{PLH} = \dfrac{2000}{295.8 \times 4}\big[0.5 + \ln 2.2\big] = 1.690 \times 1.289 = 2.18$ ns.   $\tau_P =$ 1.69 ns
  5. (c) Same sizes, $V_{DD} = 3.3$ V. $V_{th} = \dfrac{0.8 + 0.778(3.3 - 1)}{1.778} =$ 1.46 V. $\tau_{PHL} = 2.21$ ns, $\tau_{PLH} = 4.26$ ns, $\tau_P =$ 3.23 ns (about 1.9× slower).

T9 · Q5 · Sizing when the transistors add to their own load

In plain words
Making the NMOS wider gives more current, but it also makes the bucket bigger (its drain capacitance grows with $W$). So we must find the width where these two effects balance at 0.825 ns.
Theory
Refresher R ($k_R$ from $V_{th}$), B1 ($C_{load}$ adds up), B5 exact delay. (b) is B4 with the 10 % / 90 % points.
Solve
  1. $k_R = \left(\dfrac{5 - 1 - 2.4}{2.4 - 0.8}\right)^2 = \left(\dfrac{1.6}{1.6}\right)^2 = 1$ → $k_n = k_p$ → $50W_n = 20W_p$ → $W_p = 2.5\,W_n$.
  2. $C_{out} = 500 + 100 + 9W_n + 80 + 7(2.5W_n) = 680 + 26.5\,W_n$ fF.
  3. Bracket (NMOS, $u = 4.2$): $\dfrac{1.6}{4.2} + \ln(3.36 - 1) = 0.381 + 0.859 = 1.2396$.
  4. $\tau_{PHL} = \dfrac{680 + 26.5W_n}{50W_n \times 4.2} \times 1.2396 < 0.825$ → $843.0 + 32.85W_n < 173.25W_n$ → $W_n > 6.00$ µm.
  5. So Wn ≥ 6 µm, Wp ≥ 15 µm (that is why part (b) uses 6 and 15).
  6. (b) $k_n = 50 \times 6 = 300$, $k_p = 20 \times 15 = 300$ µA/V². 10 % = 0.5 V, 90 % = 4.5 V, swing 4 V, $C = 250$ fF.
  7. Fall (NMOS, $u = 4.2$): at 4.5 V sat: $150 \times 4.2^2 = 2646$ µA; at 0.5 V linear: $150[2(4.2)(0.5) - 0.25] = 592.5$ µA; average 1619 µA. $\tau_{fall} = \dfrac{250 \times 4}{1619} =$ 0.62 ns
  8. Rise (PMOS, $u = 4$): at $V_{out} = 0.5$ ($|V_{DS}| = 4.5$, sat): $150 \times 16 = 2400$ µA; at $V_{out} = 4.5$ ($|V_{DS}| = 0.5$, linear): $150[2(4)(0.5) - 0.25] = 562.5$ µA; average 1481 µA. $\tau_{rise} = \dfrac{1000}{1481} =$ 0.68 ns
Check
At $W_n = 6$: $C = 839$ fF and $\tau_{PHL} = 0.825$ ns ✓. Rise is slower than fall because the PMOS has the bigger threshold (less overdrive) ✓.

  3. A fall between any two voltages (T9 Q3: 2 V → 0.5 V). Uses the lone-segment integral of B7.
  4. Reading $k$ and $V_T$ from an I–V description (T9 Q2). No new theory, just the square law read backwards.

Check
Average-current is ≈ 4% above exact on both edges ✓ (it always overestimates). The rise is slower because $k_p < k_n$ ✓. I checked 0.703 and 1.882 ns by solving the differential equation numerically.

Q5 · Design for a target delay (Type 4)

$V_{DD} = 3.3$ V, $V_{T0,n} = 0.6$ V, $V_{T0,p} = -0.7$ V, $\mu_nC_{ox} = 100$ µA/V², $\mu_pC_{ox} = 40$ µA/V², $C_{load} = 200$ fF. Find $(W/L)_n$ and $(W/L)_p$ so that $\tau_{PHL} = \tau_{PLH} = 0.5$ ns (exact method).

What it says
The delay is now given and $k$ is the unknown. Work the exact formula backwards.
Theory
B5 exact formula, rearranged: $k = \dfrac{C}{\tau\,u}\big[\text{sat bit} + \text{log bit}\big]$. Then $W/L = k/(\mu C_{ox})$.
Plan
The bracket depends only on voltages, so compute it first for each transistor.
Solve
  1. NMOS: $u = 2.7$, bracket $= 0.4444 + 0.8210 = 1.2654$ (same as Q3).
    $k_n = \dfrac{200}{0.5 \times 2.7} \times 1.2654 = 187.5$ µA/V² → $(W/L)_n = 187.5/100 =$ 1.87
  2. PMOS: $u = 2.6$, bracket $= 1.3047$.
    $k_p = \dfrac{200}{0.5 \times 2.6} \times 1.3047 = 200.7$ µA/V² → $(W/L)_p = 200.7/40 =$ 5.02
Check
Units: fF ÷ (ns × V) = µA/V² (the bracket has no units) ✓. Plug $k_n$ back into Q3's formula: $\frac{200}{187.5 \times 2.7}\times1.2654 = 0.500$ ns ✓. Ratio $5.02/1.87 = 2.68$, a bit more than $\mu_n/\mu_p = 2.5$ because the PMOS has the bigger threshold ✓.

Q6 · Equal rise and fall (Type 4)

For the inverter of Q3, by what factor must $(W/L)_p$ change so that $\tau_{PLH} = \tau_{PHL}$? Assume $C_{load}$ does not change.

What it says
The PMOS edge (1.882 ns) is too slow. Make the PMOS wider until it matches the NMOS edge (0.703 ns).

B8 rule 1: with $C$ and voltages fixed, $\tau_{PLH} \propto 1/k_p$.

Q7 · An NMOS discharging a capacitor (Type 5) · Razavi 2.11(b)

NMOS: $W/L = 50/0.5$, $\mu_nC_{ox} = 134.3$ µA/V², $V_{TH} = 0.7$ V, $\lambda = \gamma = 0$. Source grounded, drain is node X. $C_1 = 1$ pF from X to ground, starting at 1 V. At $t=0$ the gate steps from 0 to 3 V. Sketch $V_X(t)$ and find when $V_X = 0.5$ V.

What it says
The cap is on the drain. The gate is fixed at 3 V, so $V_{GS} = 3$ V does not change. Only $V_{DS} = V_X$ changes, from 1 V to 0.5 V.
Theory
B7. Region check: $u = 3 - 0.7 = 2.3$ V. $V_{DS} \le 1 < 2.3$ → linear the whole time. So it is "segment 2 only", with a start of 1 V.
Plan
$t = \dfrac{C}{ku}\ln\dfrac{V_i(2u - V_f)}{V_f(2u - V_i)}$ with $V_i = 1$, $V_f = 0.5$. First find $k$.
Solve
  1. $k = 134.3 \times \frac{50}{0.5} = 134.3 \times 100 = 13\,430$ µA/V² $= 13.43$ mA/V².
  2. $\dfrac{C}{ku} = \dfrac{1\text{ pF}}{13.43 \times 2.3\text{ mA/V}} = 32.4$ ps.
  3. $\ln\dfrac{1 \times (4.6 - 0.5)}{0.5 \times (4.6 - 1)} = \ln\dfrac{4.1}{1.8} = \ln 2.278 = 0.823$.
  4. $t = 32.4 \times 0.823 =$ 26.6 ps
Sketch: starts at 1 V, falls toward 0 like an exponential with time constant $R_{on}C = 32.4$ ps (blue curve below).
Check (trap)
$W/L = 100$, not 50 ✓. Close to a pure RC fall ($32.4 \ln 2 = 22.4$ ps) but a bit slower, because the $-V^2$ term reduces the current ✓.

Q8 · A source follower charging a capacitor (Type 5) · Razavi 2.11(a)

Same NMOS. Now the drain is at $V_{DD} = 3$ V and $C_1$ (starting at 1 V) is on the source, node X. The gate steps from 0 to 3 V. Sketch $V_X(t)$, give its final value, and find when $V_X = 2$ V.

What it says
Fig. Q7.1(a). The cap is on the source. As X rises, $V_{GS} = 3 - V_X$ gets smaller, so the transistor slowly turns itself off.
Theory
B7. Region: $V_{DS} = 3 - V_X = V_{GS} \ge V_{GS} - V_{TH}$ always → saturated throughout. Current $= \tfrac{k}{2}(2.3 - V_X)^2$, which reaches 0 at $V_X = 2.3$ V.
Plan
$C\,\dfrac{dV_X}{dt} = \dfrac{k}{2}(2.3 - V_X)^2$ → separate → integrate $(2.3-V)^{-2}$, which gives $\dfrac{1}{2.3 - V}$.
Solve
  1. $t = \dfrac{2C}{k}\left[\dfrac{1}{2.3 - V_X} - \dfrac{1}{2.3 - 1}\right]$.
  2. At $V_X = 2$: bracket $= \dfrac{1}{0.3} - \dfrac{1}{1.3} = 3.333 - 0.769 = 2.564$ V⁻¹.
  3. $\dfrac{2C}{k} = \dfrac{2 \times 1\text{ pF}}{13.43\text{ mA/V}^2} = 148.9$ ps·V.
  4. $t = 148.9 \times 2.564 =$ 0.38 ns. Final value: 2.3 V ($= V_G - V_{TH}$), approached but never reached.
Check
The follower slows down near the end because its current falls as a square ✓. With body effect ($\gamma > 0$), $V_{TH}$ rises as X rises, so the final value would be lower than 2.3 V.

Q9 · Ring oscillator (Type 6)

(a) A ring of 5 inverters, each with $\tau_P = 50$ ps. Find the frequency. (b) A 7-stage ring oscillates at 400 MHz. Find $\tau_P$.

What it says
Fig. B9.1. (a) forwards: delay → frequency. (b) backwards: frequency → delay.
Theory
B9: $T = 2N\tau_P$ (the edge goes round twice).
Solve
(a) $T = 2 \times 5 \times 50 = 500$ ps → $f = 1/500\text{ ps} =$ 2 GHz
(b) $\tau_P = \dfrac{1}{2Nf} = \dfrac{1}{2 \times 7 \times 400\times10^6} =$ 179 ps
Check
Forgot the 2? You'd get double the frequency. $N$ must be odd, otherwise the ring just latches.

Q10 · Dynamic power (Type 7)

$V_{DD} = 3$ V, $C_{load} = 50$ fF, clock $f = 1$ GHz (one full 0→1→0 cycle per period). Find the dynamic power, and the energy burned in the PMOS each cycle.

Theory
B9: $E = CV_{DD}^2$ per cycle; half burned in each transistor.
Solve
  1. $E = 50\text{ fF} \times 3^2 = 450$ fJ $= 0.45$ pJ per cycle.
  2. $P = E \times f = 0.45\text{ pJ} \times 10^9 =$ 0.45 mW
  3. PMOS: $\tfrac12 CV_{DD}^2 =$ 0.225 pJ per cycle (the NMOS burns the other 0.225 pJ).

  2. Wrong transistor: $\tau_{PHL}$ (output falls) uses the NMOS; $\tau_{PLH}$ uses the PMOS.
