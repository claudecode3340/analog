0 · The whole story on one page

  1. A transistor is a switch. An NMOS closes when its gate is 1. A PMOS closes when its gate is 0 (Fig. 1.1).
  2. A CMOS gate is two switch networks. PMOS switches connect the output to $V_{DD}$ (pull-up). NMOS switches connect it to ground (pull-down). For every input pattern exactly one of them is closed (Fig. 1.3).
  3. Series = AND, parallel = OR. Two NMOS in parallel pull down if A or B is 1: that's NOR. Two NMOS in series pull down only if A and B are 1: that's NAND. The PMOS network is always the mirror image (series ↔ parallel).
  4. Switching threshold. Tie all inputs together and a NOR2 behaves like an inverter with a strong NMOS and a weak PMOS, so its $V_{th}$ moves down. A NAND2 is the opposite, so its $V_{th}$ moves up.
  5. Bigger gates and layout. Any expression like $Y = \overline{A(D+E)+BC}$ is built the same way. An Euler path gives the order of the gates so the layout is one neat row of transistors (Lecture 29).
  6. Delay without square-law maths. Replace each ON transistor by a resistor and each terminal by a capacitor. A width-$k$ NMOS is $R/k$; a width-$k$ PMOS is $2R/k$; each terminal has $kC$ (Lecture 30).
  7. Elmore delay. For a chain of R's and C's: delay = sum over every capacitor of (C × all the resistance between it and the rail). This is how NAND3's $12RC$ comes out (Lecture 31).
  8. Normalised delay. Divide by $\tau = 3RC$ and every gate obeys $d = g\,h + p$: effort × fanout + a fixed parasitic part. An inverter driving 4 copies of itself (FO4) has $d = 5$.
The one sentence to remember Lectures 28–29 decide which switches connect the output to which rail. Lectures 30–31 decide how fast, by turning those switches into resistors and adding up "R × C" for every capacitor that has to change.

1 · Lecture 28: NAND, NOR and their Vth In lectures

1.1 A transistor is a switch

How to read the symbol The arrow sits on the source and points the way current flows: out of the source for an NMOS (source at the bottom, toward ground), into the source for a PMOS (source at the top, from $V_{DD}$). The small circle (bubble) on the PMOS gate means "turns ON when the gate is 0". In many lecture sketches the arrow is left out; the bubble alone tells you it is a PMOS.

1.2 Why not pseudo-NMOS?

The lecture starts with one PMOS whose gate is tied to ground, so it is always on, above an NMOS. It works as an inverter, but it is wasteful.

1.3 The CMOS recipe: pull-up + pull-down

Recipe: build any CMOS gate from Y = NOT(something)
  1. Write the function as $Y = \overline{\text{expression}}$. The expression (without the bar) tells you when Y must be 0.
  2. Pull-down (NMOS): AND (·) → transistors in series; OR (+) → in parallel.
  3. Pull-up (PMOS): the dual: every series becomes parallel and every parallel becomes series. Same input letters.
  4. Check one input pattern where Y should be 0 and one where Y should be 1.
No bar in the function? (e.g. $Y = A\cdot B$ or $Y = A + BC$). A single CMOS stage can only make inverting functions. Build the inverted gate (NAND2 for $A\cdot B$) and add an inverter after it. Transistor count: a static CMOS gate with N inputs uses $2N$ transistors; the extra inverter adds 2.

1.4 NOR2 and NAND2

In these schematics a letter next to a transistor's gate means "this gate is wired to input A (or B)". The input wires are left out so the picture stays clean.

Memory hook NAND has the NMOS in series. NOR has the PMOS in series ("NOR = PMOS stack"). De Morgan: $\overline{A+B} = \bar A\cdot\bar B$: "Y is 1 when A is 0 AND B is 0", and two PMOS in series do exactly that.

1.5 W/L of transistors in series and parallel

Lecture 28 formulas (only the transistors that are ON count) $$\Big(\frac{W}{L}\Big)_{eq,\ \text{parallel}} = \sum_{k\,\in\,ON}\Big(\frac{W}{L}\Big)_k\qquad\qquad \Big(\frac{W}{L}\Big)_{eq,\ \text{series}} = \frac{1}{\displaystyle\sum_{k\,\in\,ON}\frac{1}{(W/L)_k}}$$ Two equal transistors: parallel → $2\,(W/L)$; series → $\tfrac12\,(W/L)$.

1.6 Switching threshold of NOR2 and NAND2

Step 1, the trick. $V_{th}$ is where $V_{out} = V_{in}$. For a gate with two inputs, the lecture ties both inputs together: $V_{th} = V_A = V_B = V_Y$. Now every transistor sees the same gate voltage, so the two NMOS act like one NMOS and the two PMOS act like one PMOS.

Step 2, collapse to an inverter. NOR2: NMOS in parallel → $2(W/L)_n$. PMOS in series → $\tfrac12(W/L)_p$.

Step 3, use the inverter formula from Lecture 24 with the new ratio:

$$k_{R,eff} = \frac{\mu_nC_{ox}\cdot 2(W/L)_n}{\mu_pC_{ox}\cdot\tfrac12(W/L)_p} = 4k_R\qquad\Rightarrow\qquad \sqrt{\frac{1}{k_{R,eff}}} = \tfrac12\sqrt{\frac{1}{k_R}}$$
Memorise (both inputs switching together) $$V_{th,\,INV} = \frac{V_{T0,n} + \sqrt{1/k_R}\,(V_{DD}+V_{T0,p})}{1+\sqrt{1/k_R}}$$ $$V_{th,\,NOR2} = \frac{V_{T0,n} + \tfrac12\sqrt{1/k_R}\,(V_{DD}+V_{T0,p})}{1+\tfrac12\sqrt{1/k_R}}\qquad V_{th,\,NAND2} = \frac{V_{T0,n} + 2\sqrt{1/k_R}\,(V_{DD}+V_{T0,p})}{1+2\sqrt{1/k_R}}$$ Here $k_R = k_n/k_p$ of one NMOS and one PMOS. Remember $V_{T0,p}$ is negative, so $V_{DD}+V_{T0,p} = V_{DD} - |V_{T0,p}|$.
Say it out loud "Same inverter formula, just put a ½ in front of the root for NOR and a 2 for NAND." For an N-input gate the factor is $1/N$ (NOR) or $N$ (NAND), because $k_{R,eff} = N^2k_R$ or $k_R/N^2$.
Symmetric case (lecture result) If $V_{T0,n} = |V_{T0,p}| = V_T$ and $k_R = 1$: $\;V_{th,NOR2} = \dfrac{V_T + \tfrac12(V_{DD}-V_T)}{1+\tfrac12} = \dfrac{V_{DD}+V_T}{3}$   and   $V_{th,NAND2} = \dfrac{2V_{DD}-V_T}{3}$.
A transistor sizing that makes the inverter symmetric does not make the NOR2 symmetric.
Traps ① Using the plain inverter formula for a NOR or NAND. ② Putting the 2 on the wrong gate: think "NOR has 2 strong NMOS in parallel → output pulled down early → low $V_{th}$ → small factor ½". ③ Forgetting that the formula assumes all inputs switch together. If only one input switches, a different (single-transistor) analysis is needed. That is not in the lectures.

1.7 Layout of NOR2 and NAND2 (stick diagrams)

The lecture draws the real layout: a row of PMOS (top), a row of NMOS (bottom), and vertical poly lines (the gates A, B) crossing both rows. Where a gate crosses diffusion, there is a transistor. The diffusion between two gates is a shared source/drain.

How to read a stick diagram in 3 questions ① Which node is each diffusion piece (label between the gates)? ② Which pieces touch $V_{DD}$, GND or Y through a contact? ③ Each gate line crossing a row = one transistor between its left and right pieces. Two transistors share a piece = they are connected there.

2 · Lecture 29: complex gates and Euler paths In lectures

2.1 Building $Y = \overline{A(D+E)+BC}$

Do it step by step (pull-down first)
  1. Inside out: $D+E$ → D and E in parallel.
  2. $A\cdot(D+E)$ → A in series with that pair.
  3. $BC$ → B and C in series.
  4. $\ldots + BC$ → the two branches in parallel between Y and ground.
  5. Pull-up: swap every word: $D,E$ series; A parallel to that; B, C parallel; the two groups in series between $V_{DD}$ and Y.

2.2 Equivalent W/L of the pull-down network

Use the series and parallel rules of 1.5 piece by piece, with every transistor ON:

$$\Big(\frac{W}{L}\Big)_{eq} = \underbrace{\frac{1}{\frac{1}{(W/L)_A} + \frac{1}{(W/L)_D + (W/L)_E}}}_{\text{left branch}} + \underbrace{\frac{1}{\frac{1}{(W/L)_B} + \frac{1}{(W/L)_C}}}_{\text{right branch}}$$

Only the transistors that are actually ON go in. If D is off, drop $(W/L)_D$. The worst case (weakest pull) is the input pattern with the fewest, longest paths ON. That is what designers size for. See practice P4.

2.3 Euler path: the order of the gates in the layout

In the layout every gate is one vertical poly line crossing both rows. We want one unbroken diffusion row for the NMOS and one for the PMOS, in the same gate order. An Euler path finds that order.

Recipe: Euler path
  1. Draw the pull-down graph: a dot for Y, GND and each internal node; a line (labelled with its input) for each NMOS.
  2. Draw the pull-up graph the same way ($V_{DD}$, Y, internal nodes).
  3. Find an order of letters that traces every edge once without lifting the pen, in both graphs. Try starting at a node with an odd number of edges.
  4. That letter order is the left-to-right order of the gate lines in the layout. Consecutive transistors share their diffusion.
Where to start (the quick test): count the edges touching each node. A node with an odd count must be the start or the end of the path. 0 or 2 odd nodes → a path exists (start at an odd one). More than 2 odd nodes → no single path: the row must be broken into two diffusion strips.

For our gate, pull-down node counts: Y 2 (A, B), n1 3 (A, D, E), GND 3 (D, E, C), n2 2 (B, C). Odd: n1 and GND, so start at n1. E → D → A → B → C works. Check the pull-down: n1 –E– GND –D– n1 –A– Y –B– n2 –C– GND: every NMOS once, no jumps ✓.

The lecture also repeats the slow-input correction from Lecture 26: $\tau_{PHL,actual} = \sqrt{\tau_{PHL}^2(\text{step}) + (\tau_r/2)^2}$.

3.2 The RC circuit: where "0.69 RC" comes from

The lecture writes $V_{out}/V_{in} = 1/(1+sRC)$. In time: a capacitor at $V_{DD}$ discharging through R gives $V_{out}(t) = V_{DD}e^{-t/RC}$. The 50% point:

$$\frac{V_{DD}}{2} = V_{DD}e^{-t/RC}\;\Rightarrow\; t = RC\ln 2 = 0.69\,RC$$
Why the 0.69 then disappears In Lecture 31 delays are written as plain $RC$ sums ($12RC$, $15RC$ …). The 0.69 is absorbed into the definition of $R$ (an "effective" resistance), so you just add R×C products. Use $0.69RC$ only when a question gives a real RC circuit and asks for the 50% time.

3.3 The MOSFET RC model

Memorise NMOS of width $k$: resistance $\dfrac{R}{k}$.   PMOS of width $k$: resistance $\dfrac{2R}{k}$.   Each terminal (gate, source, drain): capacitance $kC$.
$R$ is an average: $R = \dfrac{V_{DS,avg}}{I_{DS,avg}}$ over the switching event.
Intuition Width $k$ = $k$ unit transistors side by side (parallel pipes): $k$ times the current → $1/k$ of the resistance, but also $k$ times the area → $k$ times the capacitance. The PMOS is 2× worse because holes are about 2× less mobile than electrons.

3.4 The unit inverter as R's and C's

An INVx2 (everything twice as wide): resistances $R/2$, input cap $6C$, output diffusion $6C$. The lecture's sketch also shows a unit inverter with $3C$ at the input and $3C$ at the output.

3.5 NAND2 and NAND3 sized like a unit inverter

Goal: the worst pull-down and pull-up path should have resistance $R$, like the unit inverter. NMOS in series add up, so each must be wider.

Sizing rule (for unit drive) N transistors in series → each N times wider (NMOS width N; PMOS width 2N). Transistors in parallel keep the unit width (one ON alone must give R).
Any gate (complex gates too): for each transistor, find the longest series path (rail to Y) that goes through it, with $L$ transistors. Give it width $L$ (NMOS) or $2L$ (PMOS). Then every path has resistance $\le R$. Example: practice P7.
Counting capacitance at a node Add $(\text{width})\times C$ for every source/drain that touches the node. Two series transistors that share an uncontacted diffusion (like the NAND internal nodes) count it once: width × C. A question that says "fully contacted diffusion" wants each source/drain counted separately.

3.6 Elmore delay

Elmore delay $$t_{pd} \approx \sum_{\text{nodes } i} R_{i\to\text{rail}}\;C_i$$ $C_i$ = capacitance at node $i$.   $R_{i\to\text{rail}}$ = total resistance of the ON transistors between node $i$ and the rail that is pulling (ground for a falling output, $V_{DD}$ for a rising output).
Say it out loud "Every capacitor pays for every resistor between it and the rail." A capacitor far from ground (the output) pays for the whole stack; one next to ground pays for one resistor.

4 · Lecture 31: delay with fanout, d = gh + p In lectures

4.1 Unit inverter driving m inverters

$$C_{load} = 3C + 3mC,\qquad t_{pdf} = t_{pdr} = R\,(3C + 3mC) = (1+m)\cdot 3RC$$

4.2 A w-sized inverter driving m unit inverters

Width $w$: resistance $R/w$, own diffusion $3wC$:

$$t_{pd} = \frac{R}{w}\,(3wC + 3mC) = \Big(1 + \frac{m}{w}\Big)\,3RC$$
Key observation The "1" (the delay of charging its own diffusion) does not change with $w$: a bigger gate has more R-reduction but also more own C. That is the parasitic delay, and "parasitic delay is independent of size".

4.3 The normalised delay d = gh + p

Divide by $\tau = 3RC$ to get a plain number. Why $3RC$? It is the time a unit resistance $R$ needs to charge one inverter's input capacitance $3C$: a natural "tick" of the clock for this process.

Memorise $$d = \frac{t_{pd}}{\tau} = g\,h + p,\qquad \tau = 3RC,\qquad h = \frac{C_{out}}{C_{in}}$$ Inverter: $g = 1$, $p = 1$ → $d = h + 1$ (lecture: $d = \frac{m}{w} + 1$, since $h = \frac{3mC}{3wC} = \frac mw$).

The lecture only uses the inverter ($g = 1$). Tutorial 10 also needs NAND and NOR. Beyond lectures

So for any gate: size it for unit drive, then $g$ = (its input cap)/3C and $p$ ≈ (diffusion cap on its output)/3C.

Two ways to count capacitance (don't mix them) Lectures 30–31 count in $C$ (one unit transistor): an inverter input is $3C$. Tutorial 10 Q4 and Weste & Harris count in "unit inverters": an inverter input is $1$. To convert, divide by 3: a NAND2 input $4C$ = $4/3$ units. Ratios like $h = C_{out}/C_{in}$ come out the same either way, as long as top and bottom use the same unit.

4.4 FO4: the fanout-of-4 inverter

$d = 1\cdot 4 + 1 = 5$, so $t_{pd} = 5\tau = 15RC$. With the lecture's numbers $R = 10$ kΩ, $C = 0.1$ fF: $RC = 10^4 \times 10^{-16} = 1$ ps, so $t_{pd} = 15$ ps.

Contamination delay of a rising edge (same idea, other network): a NAND's PMOS are in parallel. If all inputs fall together, all PMOS turn on at once and the resistance drops to $R/N$. NAND3: $t_{cdr} = \tfrac R3\cdot 9C = 3RC$ (vs $t_{pdr} = R\cdot 9C = 9RC$ with one PMOS). Fastest case = as many parallel transistors ON as possible.

Rule for "which capacitors count" A capacitor counts if its node is connected to the output through ON transistors of the network that is pulling, and it starts at the wrong voltage. Worst case = the input farthest from the output (nearest the rail) switches last. Best case = the input nearest the output switches last.

2. Spot the type: find the row in the table below (keywords!).
3. Write the formula of that recipe before putting numbers in.
4. Solve: sizes → capacitances → resistances → formula → units.

Recipe A · build a gate
  1. Write $Y = \overline{\text{expression}}$ (use De Morgan if needed).
  2. NMOS from the expression: AND → series, OR → parallel, between Y and GND.
  3. PMOS = dual (swap series ↔ parallel), between $V_{DD}$ and Y.
  4. Check one 0-case and one 1-case.
Recipe B · Vth of a NAND/NOR
  1. $k_R = \dfrac{\mu_nC_{ox}(W/L)_n}{\mu_pC_{ox}(W/L)_p}$ for one NMOS and one PMOS.
  2. Factor $f$: NOR-N → $1/N$; NAND-N → $N$; inverter → 1.
  3. $V_{th} = \dfrac{V_{T0,n} + f\sqrt{1/k_R}\,(V_{DD}+V_{T0,p})}{1 + f\sqrt{1/k_R}}$.
  4. Backwards (design): $f\sqrt{1/k_R} = \dfrac{V_{th}-V_{T0,n}}{V_{DD}+V_{T0,p}-V_{th}}$, then solve for $k_R$ and the width ratio.
Recipe B2 · size a gate for unit drive
  1. For each transistor, find the longest rail-to-Y series path through it: $L$ transistors.
  2. Width = $L$ (NMOS) or $2L$ (PMOS).
  3. Input cap of input X = (NMOS width + PMOS width of X) × C. Then $g = $ input cap / 3C if asked.
Recipe C · equivalent W/L
  1. Keep only the ON transistors for the input pattern asked.
  2. Combine innermost groups first: parallel → add; series → $1/\sum(1/x)$.
  3. "Worst case" = the ON pattern that gives the smallest result.
Recipe D · Euler path and stick diagram
  1. Graph of each network: nodes = Y, rail, internal points; edges = transistors.
  2. Find a letter order that passes every edge once in both graphs.
  3. Draw poly lines in that order; write the node name of each diffusion piece in each row; add contacts to $V_{DD}$, GND, Y.
  4. Join pieces with the same name using metal.
Recipe E · Elmore delay in 6 steps
  1. Size the gate (widths) if not given: unit inverter n=1, p=2; series stacks N times wider.
  2. Capacitance at every node: output = all drains touching Y + the load; internal nodes = diffusions touching them.
  3. Pick the edge: falling → pull-down (NMOS, $R/k$). Rising → pull-up (PMOS, $2R/k$).
  4. Pick the worst case: the transistor nearest the rail switches last, so internal nodes start at the wrong voltage. (Best case for $t_{cd}$: the one nearest the output switches last.)
  5. For each capacitor: multiply by the resistance between it and the rail.
  6. Add. Answer like "$(12 + 5h)RC$". Divide by $3RC$ if they want $d$. For seconds, put numbers in: kΩ × fF = ps (e.g. 10 kΩ × 0.1 fF = 1 ps).
Recipe F · fanout / logical effort
  1. Find $g$ and $p$ of the gate (table in 4.3).
  2. $h = C_{out}/C_{in}$. Identical loads: $h = $ (number driven) × (load's input cap) ÷ (own input cap).
  3. $d = gh + p$, then $t = d\,\tau$ with $\tau = 3RC$ (or the $\tau$ the question gives).
Recipe G · ring oscillator · Recipe H · path arrival time G: stage delay $t_{pd} = d\tau$ (unit inverters: $d = 2$); $T = 2Nt_{pd}$; $f = 1/T$.
H: a path of gates in a row: total delay = sum of each stage's $d = gh + p$ (practice P8). With branches: for each gate $a_{out} = a_{in} + C_{load}/x + p$, take the max where paths meet; the total is the function to minimise.

T10 · Q1 · Unit inverter driving m inverters; w-sized driver; h = 4 In lectures

Estimate $t_{pd}$ for a unit inverter driving m identical unit inverters. If the driver is w times unit size, what is the delay? With R = 10 kΩ and C = 0.1 fF, find the delay for a fanout of h = 4.

In plain words
One inverter fills (or empties) its own drains plus the gates of m others. How long does that take?
Theory
Section 4.1–4.2: RC model (R for unit pull-up and pull-down, 3C per unit input, 3C own diffusion).
Plan
Load = own diffusion + all the driven inputs; delay = (driver's resistance) × (load). Then put in numbers: kΩ × fF = ps.
Solve
  1. Unit driver: $C_{load} = 3C + 3mC$ → $t_{pd} = R(3+3m)C =$ (1 + m)·3RC
  2. w-sized driver: $R/w$ and own diffusion $3wC$ → $t_{pd} = \frac Rw(3wC + 3mC) =$ (1 + m/w)·3RC
  3. h = 4 (unit driver, m = 4): $t_{pd} = 5 \times 3RC = 15RC = 15 \times 10^4\,\Omega \times 0.1\times10^{-15}\text{ F} =$ 15 ps
Check
$RC = 10^4 \times 10^{-16} = 10^{-12}$ s = 1 ps ✓. $d = 5$ matches $d = gh + p = 4 + 1$ ✓.

T10 · Q2 · FO4 delay with τ = 3 ps In lectures

Use the linear delay model to estimate the delay of the fanout-of-4 (FO4) inverter. Assume the inverter is built in a 65 nm process with τ = 3 ps.

In plain words
One inverter drives four identical inverters. How many τ does that take, and how many ps is that?
Theory
"Linear delay model" = $d = gh + p$ (section 4.3). Inverter: $g = 1$, $p = 1$.
Plan
Find $h$ (fanout), then $d$, then multiply by τ.
Solve
  1. Each load has the same input cap as the driver, four of them: $h = \dfrac{4\times3C}{3C} = 4$.
  2. $d = 1\times4 + 1 = 5$.
  3. $t = d\,\tau = 5\times3\text{ ps} =$ 15 ps
Check
Same as Q1, because there $\tau = 3RC = 3\times1\text{ ps} = 3$ ps too ✓.

T10 · Q3 · Ring oscillator with N stages, then N = 31 In lectures

A ring oscillator is built from an odd number of inverters, as in the figure. Estimate the frequency of an N-stage ring oscillator. What is the frequency of a 31-stage ring oscillator if τ = 3 ps in a 65 nm process?

In plain words
An edge runs round the loop. For one full period it must go round twice (once rising, once falling), as in Lecture 25.
Theory
$T = 2N t_{pd}$ (Lecture 25) and $t_{pd} = d\tau$ with $d = gh + p$.
Plan
Find one stage's $d$ (each stage drives one inverter, so $h = 1$), then $T$, then $f = 1/T$.
Solve
  1. $d = 1\cdot1 + 1 = 2$ → $t_{pd} = 2\tau$.
  2. $T = 2N\cdot 2\tau = 4N\tau$ → f = 1/(4Nτ)
  3. $N = 31$: $f = \dfrac{1}{4 \times 31 \times 3\text{ ps}} = \dfrac{1}{372\text{ ps}} =$ 2.69 GHz
Check
$h = 1$, not 0: each stage drives one inverter ✓. Forgetting the "2 laps" gives 5.4 GHz, which is wrong.

T10 · Q4 · Arrival time of a branching path, and the optimisation problem Beyond lectures

The circuit has non-uniform branching, reconvergent fanout and a wire load. Inputs arrive at time 0. Write the output arrival time as a function of the gate drives, and form the optimisation problem.

In plain words
Each gate's delay depends on what it drives. Bigger gates are faster but load the gate before them. Write each gate's delay with $d = (\text{load cap})/x + p$, add along each path, and take the later path where two paths meet.
Theory
Section 4.3: $d = gh + p$ with $h = C_{out}/(g\,x)$, so $g\,h = C_{out}/x$. Input cap of a gate with drive $x$ is $g\,x$ (in unit-inverter caps). All delays in units of $\tau$.
Plan
Arrival time at each output: $a_{out} = a_{in} + \dfrac{C_{load}}{x} + p$. At X4, use the later of the two arriving signals (max).
Solve
  1. Inverter 1 (x = 1) drives X2 and X3: $a_1 = \dfrac{\frac43x_2 + \frac53x_3}{1} + 1$
  2. X2 (NAND2) drives one input of X4 (NOR3, g = 7/3): $a_2 = a_1 + \dfrac{\frac73x_4}{x_2} + 2$
  3. X3 (NOR2) drives another input of X4: $a_3 = a_1 + \dfrac{\frac73x_4}{x_3} + 2$
  4. X4 (NOR3) drives the wire and X5: $a_4 = \max(a_2, a_3) + \dfrac{10 + x_5}{x_4} + 3$
  5. X5 (inverter) drives $C_5$: aout = a4 + 12/x5 + 1
  6. Optimisation problem: minimise $a_{out}(x_2, x_3, x_4, x_5)$ over $x_2, x_3, x_4, x_5 > 0$ (sizes can't be negative; in practice also ≥ 1).
Optional Solving it (numerically, or by setting each partial derivative to 0): the best is $x_2 = x_3 = 1.62$, $x_4 = 3.37$, $x_5 = 6.36$, giving $a_{out} = 23.5\,\tau$ (all drives = 1 gives $35.3\,\tau$).
Check
Units: every term is a capacitance ÷ a drive → a plain number of $\tau$ ✓. The max appears because X4 must wait for its slower input ✓.

T10 · Q5 · NOR2 sized for unit drive; Elmore delays driving h NOR2s In lectures

Sketch a 2-input NOR with widths giving rise and fall resistances equal to a unit inverter. Compute the rising and falling delays driving h identical NOR gates (Elmore). Assume every source/drain is fully contacted.

In plain words
Size the gate so its worst pull-up and pull-down are both $R$. Then count capacitors and apply Elmore for each edge.
Theory
3.5 (sizing), 3.5 amber box (counting caps), Recipe E.
Plan
Widths → input cap (for the load) → cap at Y and at the internal node → falling with one NMOS → rising through the PMOS stack, worst case.
Solve
  1. Widths: two PMOS in series must total $R$ → each $R/2 = 2R/w$ → $w = 4$. NMOS alone must give $R$ → width 1.
  2. Input cap per input: $4C + 1C = 5C$. Load: $h \times 5C$.
  3. Output node: PMOS drain $4C$ + two NMOS drains $1C + 1C$ = $6C$, plus load: $(6 + 5h)C$.
  4. Internal PMOS node (fully contacted, both sides counted): $4C + 4C = 8C$.
  5. Falling (one NMOS, R): $t_{pdf} = R\,(6+5h)C =$ (6 + 5h) RC
  6. Rising, worst case: before, A = 1 and B = 0, so Y is low and the internal node is pulled low too (through PMOS B). Then A falls (A is the PMOS nearest $V_{DD}$, so it switches last): $t_{pdr} = \tfrac R2\cdot 8C + (\tfrac R2 + \tfrac R2)(6+5h)C =$ (10 + 5h) RC
Check
Rising is slower because of the internal node ✓. In $\tau$ units: $(6+5h)/3 = \frac53h + 2$: $g = 5/3$, $p = 2$, exactly the NOR2 row in 4.3 ✓. (Counting the shared internal node once would give $4C$ and $t_{pdr} = (8+5h)RC$.)

T10 · Q6 · Unloaded AND-OR-INVERT gate, caps from the stick diagram In lectures

Find the rising and falling delays of an unloaded AOI gate using Elmore. Estimate diffusion capacitance from a stick diagram. (We take the AOI21: $Y = \overline{AB + C}$, the usual textbook AOI.)

In plain words
Same as Q5, but first build the gate (Recipe A), then lay it out (Euler path) to see which diffusions are shared.
Theory
Recipe A (build), Recipe D (Euler path, shared diffusions), Recipe B2 (sizing), Recipe E (Elmore).
Plan
Euler path: order A, B, C. Pull-down row: Y –A– n1 –B– GND –C– Y. Pull-up row: p1 –A– $V_{DD}$ –B– p1 –C– Y.
Solve
  1. Widths: NMOS A, B = 2 (series), C = 1. PMOS all 4 (two in series on every path).
  2. Output Y: NMOS A drain $2C$ + NMOS C drain $1C$ + PMOS C drain $4C$ = $7C$.
  3. n1 (between A and B, shared): $2C$.   p1: two diffusion pieces, $4C + 4C = 8C$.
  4. Falling, worst case: before, A = 1, B = 0, C = 0, so n1 is high (connected to Y through A). Then B (nearest ground) rises: $t_{pdf} = \tfrac R2\cdot 2C + R\cdot 7C =$ 8 RC
  5. Rising, worst case: before, A = B = 1 and C = 0, so Y and p1 are both low. Then A (or B) falls and p1 must be charged too: $t_{pdr} = \tfrac R2\cdot 8C + R\cdot 7C =$ 11 RC
Check
Through C alone the fall is only $7RC$ (best case) ✓. If your tutor means AOI22 ($\overline{AB+CD}$), the method is identical; the Euler order A B D C works for it (practice P5).

T10 · Q7 · Worst-case Elmore parasitic delay of an n-input NOR In lectures

Find the worst-case Elmore parasitic delay of an n-input NOR gate (no external load).

In plain words
A NOR-n has n PMOS in series: the rising edge through that long stack is the slow one. "Parasitic" = no external load, only the gate's own capacitances.
Theory
3.5 (series stacks N× wider; counting caps) and 3.6 (Elmore). Worst case: the PMOS nearest $V_{DD}$ switches last, so every internal node starts low.
Plan
Sizes → cap at each node → resistance from $V_{DD}$ to each node → Elmore sum.
Solve
  1. Sizing: n PMOS in series → each width $2n$ (resistance $R/n$). NMOS width 1.
  2. Output: PMOS drain $2nC$ + n NMOS drains $n\cdot C$ = $3nC$.
  3. Internal PMOS nodes: $n-1$ of them, each $2nC$ (shared diffusion). Node $i$ (counted from $V_{DD}$) is $i\cdot R/n$ from the rail.
  4. $t_{pdr} = \sum_{i=1}^{n-1}\frac{iR}{n}\,2nC + R\cdot 3nC = 2RC\cdot\frac{n(n-1)}{2} + 3nRC =$ (n² + 2n) RC
Check
n = 2: $8RC$. That equals Q5 with h = 0 when the internal node is counted once ($4C$) ✓. Grows like $n^2$: why wide NOR gates are avoided.

T10 · Q8 · A 4x inverter In lectures

Let a 4x inverter have transistors four times as wide as those of a unit inverter. If a unit inverter has three units of input capacitance and parasitic delay $p_{inv}$, what is the input capacitance of a 4x inverter? What is the logical effort? What is the parasitic delay?

In plain words
Make every transistor 4× wider. What happens to its input cap, its "effort" and its built-in delay?
Theory
4.2: width $w$ → resistance $R/w$, every capacitance $\times w$; "parasitic delay is independent of size". 4.3: $g$ compares input cap to an inverter of the same drive.
Plan
Scale each quantity by 4 and see which ratios stay the same.
Solve
  1. Input cap: $4 \times 3 =$ 12 units
  2. Logical effort: it is still an inverter: input cap and output current both ×4, same ratio → g = 1
  3. Parasitic delay: own diffusion ×4 but resistance ÷4 → p = pinv
Check
Lecture 31: $t_{pd} = (1 + \frac mw)3RC$. The "1" (parasitic part) has no $w$ in it ✓.

T10 · Q9 · Logical effort when the PMOS is 3× weaker Beyond lectures

Consider a process in which pMOS transistors have three times the effective resistance of nMOS transistors. Calculate the logical efforts of a 2-input NAND gate and a 2-input NOR gate if they are designed with equal rising and falling delays.

In plain words
Same method as Fig. 4.3, but a PMOS now needs width 3 (not 2) to match one NMOS.
Theory
4.3: $g$ = input cap of the gate ÷ input cap of an inverter with the same drive. Sizing rule of 3.5.
Plan
Size the reference inverter, then the NAND2 and NOR2 for equal rise/fall, then divide input caps.
Solve
  1. Reference inverter: NMOS 1, PMOS 3 → input cap $4$.
  2. NAND2: NMOS in series → width 2; PMOS in parallel → width 3. Input cap $2 + 3 = 5$ → g = 5/4
  3. NOR2: NMOS width 1; PMOS in series → width 6. Input cap $1 + 6 = 7$ → g = 7/4

P1 · Vth of INV, NOR2 and NAND2 from the same transistors In lectures

A process has $V_{DD} = 3.3$ V, $V_{T0,n} = 0.6$ V, $V_{T0,p} = -0.7$ V, $\mu_nC_{ox} = 60$ µA/V², $\mu_pC_{ox} = 25$ µA/V². Every transistor has $W/L = 2$. Find the switching threshold $V_{th}$ of (a) an inverter, (b) a NOR2 and (c) a NAND2, with all inputs switching together.

In plain words
Same transistors, three different wirings. Where does each one flip?
Theory
1.6: $V_{th} = \dfrac{V_{T0,n} + f\sqrt{1/k_R}(V_{DD}+V_{T0,p})}{1 + f\sqrt{1/k_R}}$ with $f = 1$ (INV), ½ (NOR2), 2 (NAND2).
Plan
Compute $k_R$ for one NMOS and one PMOS, then plug in three values of $f$.
Solve
  1. $k_R = \frac{60\times2}{25\times2} = 2.4$, $\sqrt{1/k_R} = 0.6455$, $V_{DD}+V_{T0,p} = 2.6$ V.
  2. Inverter (f = 1): $\frac{0.6 + 0.6455\times2.6}{1.6455} =$ 1.385 V
  3. NOR2 (f = ½): $\frac{0.6 + 0.3227\times2.6}{1.3227} =$ 1.088 V
  4. NAND2 (f = 2): $\frac{0.6 + 1.291\times2.6}{2.291} =$ 1.727 V
Check
Order NOR2 < INV < NAND2 ✓. NOR2 has two strong NMOS in parallel pulling down early.

P2 · Size a NOR2 and a NAND2 for Vth = VDD/2 In lectures

Using the process of P1, find the ratio $(W/L)_p/(W/L)_n$ that gives $V_{th} = V_{DD}/2 = 1.65$ V for (a) an inverter, (b) a NOR2 and (c) a NAND2 (all inputs together).

In plain words
We want each gate to flip exactly in the middle. How big must the PMOS be compared with the NMOS?
Theory
Recipe B, step 4 (backwards): $f\sqrt{1/k_R} = \dfrac{V_{th}-V_{T0,n}}{V_{DD}+V_{T0,p}-V_{th}}$, then $\dfrac{(W/L)_p}{(W/L)_n} = \dfrac{\mu_nC_{ox}/\mu_pC_{ox}}{k_R}$.
Plan
The right side is the same for all three gates. Divide by $f$, square, invert to get $k_R$, then the width ratio.
Solve
  1. $f\sqrt{1/k_R} = \frac{1.65 - 0.6}{2.6 - 1.65} = \frac{1.05}{0.95} = 1.105$.
  2. Inverter ($f = 1$): $k_R = 1/1.105^2 = 0.819$ → ratio $= \frac{2.4}{0.819} =$ 2.93
  3. NOR2 ($f = \tfrac12$): $\sqrt{1/k_R} = 2.211$ → $k_R = 0.2046$ → ratio $= \frac{2.4}{0.2046} =$ 11.7
  4. NAND2 ($f = 2$): $\sqrt{1/k_R} = 0.5526$ → $k_R = 3.274$ → ratio $= \frac{2.4}{3.274} =$ 0.73
Check
NOR2 needs a huge PMOS (two weak hole-devices in series); NAND2 needs one smaller than its NMOS. One more reason designers prefer NAND ✓.

P3 · Symmetric NOR2 and NAND2 In lectures

An inverter is symmetric: $k_R = 1$ and $V_{T0,n} = |V_{T0,p}| = 0.6$ V, with $V_{DD} = 3.3$ V. The same transistor sizes are used to build a NOR2 and a NAND2. Find the switching threshold of each.

In plain words
The inverter flips at 1.65 V. Does a NOR2 or NAND2 built from the same transistors still flip there?
Theory
1.6 symmetric case: $V_{th,NOR2} = \dfrac{V_{DD}+V_T}{3}$, $V_{th,NAND2} = \dfrac{2V_{DD}-V_T}{3}$.
Plan
Plug in directly.
Solve
NOR2: $\frac{3.3 + 0.6}{3} =$ 1.30 V.   NAND2: $\frac{6.6 - 0.6}{3} =$ 2.00 V.
Check
The inverter's 1.65 V lies between them ✓. Using the general formula with $f = ½$: $\frac{0.6 + 0.5\times2.7}{1.5} = 1.30$ ✓.

P4 · Equivalent W/L of the complex gate In lectures

In the pull-down network of $Y=\overline{A(D+E)+BC}$ every NMOS has $W/L = 2$. Find $(W/L)_{eq}$ (a) when all inputs are 1, and (b) in the worst case in which the network still pulls Y low.

In plain words
Replace the whole network by one equivalent transistor. How wide is it with everything on, and with the weakest path that still works?
Theory
1.5 and 2.2: parallel → add; series → $1/\sum(1/x)$. Only ON transistors count.
Plan
Combine D ∥ E first, then series with A; B series C; then the two branches in parallel.
Solve
  1. (a) D ∥ E = 4. Left: $\frac{1}{\frac12 + \frac14} = \frac43$. Right: $\frac{1}{\frac12+\frac12} = 1$. Total 7/3 ≈ 2.33
  2. (b) Weakest pattern that still pulls down: one branch with only two series devices, e.g. A = D = 1, all others 0: $\frac{1}{\frac12+\frac12} =$ 1

Worst case 1 = a unit inverter NMOS ✓. That is exactly why each series device gets width 2 (sizing rule in 3.5).

P5 · Euler path and stick order for an AOI22 In lectures

For $Y = \overline{AB + CD}$: (a) draw the pull-down and pull-up networks, (b) draw their graphs, (c) find a common Euler path and give the gate order for the layout.

In plain words
Build the gate, then find one order of the four gate lines so both diffusion rows are unbroken.

Recipe A (build) and Recipe D / 2.3 (Euler path, odd-node rule).
Plan
Networks → graphs → count edges per node → start at an odd node → trace.

P6 · NAND2 driving h NAND2s: Elmore, and where g and p come from In lectures

A NAND2 sized for unit drive (NMOS width 2, PMOS width 2) drives h identical NAND2 gates. Using the Elmore model, find the worst-case falling and rising propagation delays. Then write the rising result as $d = gh + p$.

In plain words
Count the capacitors, pick the worst input pattern, apply Elmore. Then divide by $3RC$.
Theory
Recipe E (Elmore) and 4.3 ($d = t/3RC$).
Plan
Output cap $6C + 4hC$; internal node $2C$. Falling: A (bottom) switches last. Rising: one PMOS on.
Solve
  1. Output: two PMOS drains $2C + 2C$ + top NMOS $2C$ = $6C$; load $h\cdot4C$. Internal n1: $2C$.
  2. $t_{pdf}$: before, A = 0, B = 1 (n1 charged high). A rises: $\tfrac R2\cdot2C + R(6+4h)C =$ (7 + 4h) RC
  3. $t_{pdr}$: one PMOS (resistance $2R/2 = R$); n1 is in the NMOS network, which is not pulling, so it does not count: (6 + 4h) RC
  4. Divide the rising result by $3RC$: $\frac{6+4h}{3} = \frac43h + 2$ → $g = 4/3$, $p = 2$ ✓.
Check
$d = gh + p$ is just Elmore divided by $3RC$: the link between Lecture 30 and Lecture 31 ✓.

P7 · Size a complex gate for unit drive In lectures

Choose transistor widths for $Y=\overline{A(D+E)+BC}$ so that its worst-case pull-up and pull-down resistances equal those of a unit inverter (NMOS 1, PMOS 2). Give the input capacitance of each input. (Optional: the logical effort of each input.)

P8 · Delay of a two-gate path In lectures

A unit inverter drives one input of a unit NAND2 (input cap $4C$). The NAND2 drives a load of $12C$. Using $d = gh + p$, find the total path delay in units of τ, and in ps if τ = 3 ps. Check the result with Elmore.

In plain words
Two gates in a row: the total delay is the sum of the two stage delays.
Theory
4.3: $d = gh + p$ per stage; Recipe H (path = sum of stages).

For each stage: what does it drive ($C_{out}$), what is its own input cap ($C_{in}$), then $h$, then $d$.
Solve
  1. Stage 1 (inverter): $h_1 = 4C/3C = 4/3$ → $d_1 = 1\cdot\frac43 + 1 = 2.33$.
  2. Stage 2 (NAND2): $h_2 = 12C/4C = 3$ → $d_2 = \frac43\cdot3 + 2 = 6$.
  3. $D = 2.33 + 6 =$ 8.33 τ $= 8.33\times3 =$ 25 ps

Compute both and compare.
Solve
Gate: $3.84 \times 1 \times 0.5 =$ 1.92 fF. Drain: $1\times1.5\times0.56 + 2(1+1.5)\times0.035 = 0.84 + 0.175 =$ 1.02 fF.
Check
Same order of magnitude, so "C on every terminal" is a fair simplification ✓.

R4 · Folding and shared diffusion (Razavi Ex. 2.10) Optional

A transistor has W = 20 µm and drain length E = 1.5 µm (Table 2.1 values as in R3). Find its drain junction capacitance $C_{DB}$. Then fold it into two 10 µm fingers that share one drain and find $C_{DB}$ again.

In plain words
Same transistor, different layout. Does sharing a drain make it faster?
Theory
$C_{DB} = WEC_j + 2(W+E)C_{jsw}$, with the drain width that is actually drawn.
Plan
Unfolded drain is 20 µm wide; folded shared drain is 10 µm wide.
Solve
Unfolded: $20(1.5)(0.56) + 2(21.5)(0.035) =$ 18.3 fF. Folded: $10(1.5)(0.56) + 2(11.5)(0.035) =$ 9.2 fF.
Check
Half the drain cap ✓. Same reason the Euler-path layout (shared diffusions) makes gates faster.

R5 · Three-stage ring oscillator (Razavi §15.2) In lectures

A ring oscillator has three inverters, each with delay $T_D = 50$ ps. Find the period and the frequency. Why must the number of stages be odd?

In plain words
An edge chases itself round three inverters. How long is one full cycle?
Theory
$T = 2NT_D$ (two laps per period).
Plan
Plug N = 3 and $T_D$ = 50 ps.
Solve
$T = 6T_D = 300$ ps → f = 3.33 GHz. With an even N the ring has a stable state (alternating 0/1) and just latches.
Check
Razavi's own statement: "three stages give a period of $6T_D$" ✓. Optional Razavi also shows a 3-stage ring needs a small-signal gain of at least 2 per stage to start.
