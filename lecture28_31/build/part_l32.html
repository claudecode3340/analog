Pattern to notice In every case the $h$ term has the same slope: $\frac53h$ for NAND3 and $\frac73h$ for NOR3 (the best-case ones divide it by 3). That slope is the logical effort $g$: $g_{NAND3} = 5C/3C = 5/3$, $g_{NOR3} = 7C/3C = 7/3$. The constant part is the parasitic delay $p$; it depends on the input pattern.
Which p should I use? The logical-effort table (section 5) uses the simple value $p = n$ for an n-input NAND/NOR (output diffusion only). Elmore's worst case is bigger (NAND3: 4 or 5) because it also counts internal nodes. Rule: if the question says "Elmore" or "find $t_{pdf}$", use Elmore. If it says "logical effort", "linear delay model" or "path delay", use the table.

5 · Lecture 33: the linear delay model and gate drive In lectures

5.1 d = f + p

Memorise $$d = \frac{t_{pd}}{\tau} = \underbrace{g\,h}_{f}\; + \;p,\qquad \tau = 3RC$$ $g$ = logical effort, $h = C_{out}/C_{in}$ = electrical effort (fanout), $f = gh$ = effort delay (also called stage effort), $p$ = parasitic delay.
$C_{out}$ = the load the gate drives, not counting its own diffusion (that is inside $p$).

Inverter: $g = 1$, $p = 1$ (in units of $p_{inv}$), so $d = h + 1$. A unit inverter driving $h$ inverters: $t_{pdf} = 3RC + 3hRC$, so $d = 1 + h$ ✓.

5.2 Logical effort of common gates (Lecture 33 table)

Where the numbers come from (no memorising needed) Size the gate for unit drive, then divide its input cap by $3C$. NAND-n: NMOS width n + PMOS width 2 → $(n+2)/3$. NOR-n: NMOS 1 + PMOS 2n → $(2n+1)/3$.

5.3 Drive of a gate

Memorise $$x = \frac{C_{in}}{g}\qquad(C_{in}\text{ normalised: divide by }3C)\qquad\Longrightarrow\qquad d = \frac{C_{out}}{x} + p,\qquad f = \frac{C_{out}}{x}$$ Proof: $f = gh = g\dfrac{C_{out}}{C_{in}} = g\dfrac{C_{out}}{g\,x} = \dfrac{C_{out}}{x}$. Example: NAND2X1 has $C_{in} = 4C$ → $4/3$, $x = \frac{4/3}{4/3} = 1$. NAND2X2: $8C$ → $8/3$, $x = 2$.

6 · Lecture 34: limits of the model and multistage paths In lectures

6.1 Limitations of the linear delay model

  1. Input rise/fall time. The model assumes a sharp input. A slow input edge turns the transistor on gradually, so the delay grows (Lecture 26: $\tau = \sqrt{\tau_{step}^2 + (\tau_r/2)^2}$).
  2. Input arrival time. When several inputs switch, which one arrives last changes the delay (the Elmore worst/best cases of 4.5–4.6).
  3. Velocity saturation. In short-channel transistors the carriers stop speeding up at high electric field. Razavi (§11.2, §17.2.3): in the extreme case $I_D = WC_{ox}(V_{GS}-V_{TH})\,v_{sat}$: current grows linearly with overdrive, not as a square, and saturates at a lower $V_{DS}$. So a real transistor gives less current than the square law, and series stacks are a bit less bad than the model predicts.

6.3 Why the branching effort is needed

Following the top path: $f_1 = 1\times\frac{15+15}{5} = 6$ (the first inverter must charge both branches), $f_2 = 1\times\frac{90}{15} = 6$, so $F = 36$. But $G = 1$ and $H = 90/5 = 18$ give only $GH = 18$. The missing factor 2 is the branching: half the current goes to the other branch. $b = \frac{15+15}{15} = 2$ and $F = GBH = 36$ ✓.

6.4 Minimum delay: make every stage work equally hard

$F$ is fixed by the path (it does not depend on $x, y, z$), and $P$ is fixed too. So minimising $D$ means minimising $\sum f_i$ while $\prod f_i = F$ stays constant. That happens when all stage efforts are equal.

Memorise (N-stage path) $$\hat f = F^{1/N} = (GBH)^{1/N},\qquad \hat D = N\,F^{1/N} + P$$ Then size the gates from the output backwards: $\;C_{in,i} = \dfrac{g_i\,C_{out,i}}{\hat f}$ (from $\hat f = g\,C_{out}/C_{in}$).
Say it out loud "Multiply to get F, take the N-th root to get f̂, then walk backwards: each input cap = g × what it drives ÷ f̂."
Worked: the Lecture 34 path (Fig. 6.2)
  1. $G = 1\cdot\frac53\cdot\frac43\cdot1 = \frac{20}{9} = 2.22$; $H = 45/10 = 4.5$; $B = 1$ → $F = 10$.
  2. $\hat f = 10^{1/4} = 1.78$; $P = 1 + 2 + 2 + 1 = 6$ → $\hat D = 4\times1.78 + 6 =$ 13.1 τ
  3. Backwards: $z = \frac{1\times45}{1.78} = 25.3$; $y = \frac{\frac43\times25.3}{1.78} = 19.0$; $x = \frac{\frac53\times19.0}{1.78} = 17.8$.
  4. Check the first stage: $\frac{1\times17.8}{1.78} = 10$ = the given input cap ✓.

6.5 How many stages are best? Optional

Weste & Harris show the best stage effort is about 4 (between 3 and 6 is fine), so $\hat N \approx \log_4 F$. For $F = 1000$: $\log_4 1000 = 5.0$ stages, $D = 5\times1000^{1/5} + 5 = 24.9\,\tau$. Not in your lectures.
