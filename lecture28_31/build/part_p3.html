P16 · Size a branched path and give the transistor widths In lectures

An inverter with input capacitance 6 drives a NOR3. The NOR3 drives two identical NAND2 gates; the path continues through one of them, which drives a load of 60. (a) Find the minimum path delay. (b) Find the input capacitance of the NOR3 and NAND2. (c) Give the NMOS and PMOS widths of each.

In plain words
Same job as Lecture 35's example, with different gates: fastest A→B delay, then real transistor sizes.
Theory
Recipe I (6.4, 7.1) and the Cin → widths recipe (7.2).
Plan
G, B, H → F → f̂ → D; then sizes backwards; then $k = C_{in}/(\text{unit cap})$.
Solve
  1. $G = 1\times\frac73\times\frac43 = \frac{28}{9}$; $B = 2$; $H = 60/6 = 10$ → $F = \frac{28}{9}\times2\times10 = 62.2$.
  2. $\hat f = 62.2^{1/3} = 3.96$; $P = 1 + 3 + 2 = 6$ → $\hat D = 3\times3.96 + 6 =$ 17.9 τ
  3. NAND2: $C_{in} = \frac{\frac43\times60}{3.96} =$ 20.2. NOR3 drives $2\times20.2$: $C_{in} = \frac{\frac73\times40.4}{3.96} =$ 23.8. Check: $\frac{1\times23.8}{3.96} = 6$ ✓
  4. NAND2: $k = 20.2/4 = 5.05$ → NMOS $2k = 10.1$, PMOS $2k = 10.1$. NOR3: $k = 23.8/7 = 3.40$ → NMOS $3.4$, PMOS $6k = 20.4$.
Check
Each stage has effort 3.96 ≈ 4: close to the best stage effort, so 3 stages is the right count ✓.

P17 · Best number of stages for F = 500 In lectures

A path has path effort F = 500 and you may add inverters ($p_{inv} = 1$). Estimate the best number of stages with the ρ rule, then confirm by computing D for N = 3 … 7.

In plain words
How many equal stages should share an effort of 500?
Theory
7.4: $\hat N = \ln F/\ln\rho$ with $\rho = 3.59$ (or 4 by hand); $D = NF^{1/N} + N$.
Plan
Estimate, then check the neighbours.
Solve
  1. $\hat N = \frac{\ln 500}{\ln 3.59} = \frac{6.21}{1.28} = 4.86$ (by hand: $\log_4 500 = 4.48$) → try 4, 5.
  2. D: N = 3: 26.8; N = 4: 22.9; N = 5: 22.3 τ (best); N = 6: 22.9; N = 7: 24.0.
Check
The curve is flat near the optimum: 4, 5 or 6 stages are all within 3% ✓. Rounding to the nearest sensible N is fine.

P18 · AOI22 + inverter or NAND–NAND? In lectures

Implement $F = AB + CD$ driving a path electrical effort H = 10, (a) as AOI22 + inverter and (b) as NAND2–NAND2. Find the minimum delay of each. Which is faster?

In plain words
Lecture 36's comparison with a heavier load.
Theory
8.2: AOI22 $g = 2$, $p = 4$; inverter $1, 1$; NAND2 $\frac43, 2$. Two stages: $\hat D = 2\sqrt F + P$.
Plan
F = GH for each, then D.
Solve
  1. (a) $F = 2\times1\times10 = 20$; $D = 2\sqrt{20} + 5 =$ 13.9 τ
  2. (b) $F = \frac{16}{9}\times10 = 17.8$; $D = 2\sqrt{17.8} + 4 =$ 12.4 τ → NAND–NAND is faster.
Check
Same winner as the lecture's H = 5 case (11.3 vs 9.96 τ) ✓.

P19 · An asymmetric NAND2 with a 4:1 split In lectures

In the reset NAND2 of Fig. 8.5, give RESET' only $R/5$ of the pull-down resistance. Find the NMOS widths and the logical effort of input A and of RESET'. (PMOS: A 2, RESET' 1, as before.)

In plain words
Make the A transistor even smaller, by making RESET' even bigger.
Theory
8.5: series resistances must add to $R$; an NMOS of resistance $R/w$ has width $w$.
Plan
Split $R$ into $\frac45R + \frac15R$, then widths, then $g$.
Solve
  1. A: $\frac45R$ → width $\frac54$. RESET': $\frac15R$ → width 5.
  2. $g_A = \frac{5/4 + 2}{3} =$ 13/12 ≈ 1.08; $g_{RESET} = \frac{5 + 1}{3} =$ 2
Check
$g_A$ falls from $\frac{10}{9} = 1.11$ only slightly: returns diminish, because the PMOS (width 2) dominates A's input cap ✓.

P20 · Logical effort of skewed gates In lectures

Find $g_u$, $g_d$ and $g_{avg}$ of (a) a HI-skew NOR2 (PMOS 4, 4; NMOS ½, ½) and (b) a LO-skew NAND2 (PMOS 1, 1; NMOS 2, 2).

In plain words
For each edge, how much input cap does this gate need compared with an inverter giving the same current?
Theory
9.1: rising → reference inverter with the same pull-up current; falling → same pull-down current.
Plan
Find each edge's resistance, match it with an inverter (cap 3 for $R$, cap 1.5 for $2R$), divide.
Solve
  1. (a) Input cap $4 + \frac12 = 4.5$. Rise: two PMOS of $2R/4$ in series = $R$ → ref cap 3 → $g_u = 1.5$. Fall: one NMOS ½ = $2R$ → ref cap 1.5 → $g_d = 3$. $g_{avg} =$ 2.25
  2. (b) Input cap $1 + 2 = 3$. Rise: one PMOS of width 1 = $2R$ → ref 1.5 → $g_u = 2$. Fall: two NMOS of $R/2$ = $R$ → ref 3 → $g_d = 1$. $g_{avg} =$ 1.5
Check
Matches the lecture's values ✓. The favoured edge always has the smaller $g$.

P21 · Pseudo-NMOS with a weaker pull-up In lectures

Redo Lecture 37's pseudo-NMOS sizing, but make the PMOS 8× weaker than the NMOS (PMOS width $x/4$). Find x and the PMOS width. Will $V_{OL}$ be higher or lower than in the lecture's design?

In plain words
A weaker load fights less, so the NMOS can be smaller; but the rising edge gets slower.
Theory
9.3: net pull-down current at $V_{DD}/2$ = unit inverter's.
Plan
PMOS width $x/4$ → resistance $2R/(x/4) = 8R/x$.
Solve
  1. $\frac{V/2}{R/x} - \frac{V/2}{8R/x} = \frac{V/2}{R}$ → $x - \frac x8 = 1$ → $x = \frac87 =$ 1.14
  2. PMOS width $\frac x4 =$ 2/7 ≈ 0.29
  3. $k_n/k_p = 8$ (vs 4) → $V_{OL}$ is lower (Fig. 9.4 trend), but the pull-up current is only $\frac17$ of a unit → slower rising edge.
Check
Setting the PMOS to zero gives $x = 1$, a plain unit NMOS ✓.

P22 · Input positioning in a NAND3 In lectures

In a NAND3 driving h NAND3s, signal S arrives much later than the other two. Which NMOS should S drive, and what is the falling delay then? What if you connect it wrongly?

In plain words
The two early inputs have already switched on their transistors. Put S where the least charge is left to remove.
Theory
8.6 and the NAND3 table (4.6).
Plan
Compare S on the top (outer) transistor with S on the bottom (inner).
Solve
  1. S on the outer (top, nearest Y): internal nodes already at 0 → $t = (9+5h)RC$, $d = 3 + \frac53h$ (fast)
  2. S on the inner (bottom): both internal nodes must also discharge → $(12+5h)RC$, $d = 4 + \frac53h$.
Check
A free 1τ saving just by wiring ✓.
