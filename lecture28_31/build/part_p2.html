P9 · NAND3 driving h NAND3s: all four delays In lectures

A unit-drive NAND3 (NMOS width 3, PMOS width 2) drives $h = 4$ identical NAND3 gates. Using the Elmore model, find $t_{pdf}$, $t_{cdf}$, $t_{pdr}$ and $t_{cdr}$ in terms of $RC$, and the normalised delays $d$. State the input pattern for each.

In plain words
Same gate, four input patterns. For each, ask: which transistors pull, and which capacitors start at the wrong voltage?
Theory
4.6 (NAND3 table) and Recipe E. Load per gate $5C$ → $5hC = 20C$.
Plan
Output cap $9C + 20C = 29C$; internal nodes $3C$ each. Put $h = 4$ into each formula.
Solve
  1. $t_{pdf}$ (A=0, B=C=1 → A=1): $29C\cdot R + 3C\cdot\frac{2R}{3} + 3C\cdot\frac R3 =$ 32 RC, $d = 4 + \frac{20}{3} = 10.7$
  2. $t_{cdf}$ (A=B=1, C=0 → C=1): $29C\cdot R =$ 29 RC, $d = 9.67$
  3. $t_{pdr}$ (all 1 → A=0): $29C\cdot R + 3C\cdot R + 3C\cdot R =$ 35 RC, $d = 11.7$
  4. $t_{cdr}$ (all 1 → all 0): $29C\cdot\frac R3 =$ 9.67 RC, $d = 3.22$
Check
Best ≤ worst for each edge ✓. Each $d$ has the slope $\frac53h$ (or $\frac59h$ with 3 PMOS on) ✓.

P10 · NOR3 driving h NOR3s In lectures

A unit-drive NOR3 (PMOS width 6, NMOS width 1) drives $h$ identical NOR3 gates. Find $t_{pdf}$, $t_{cdf}$ and $t_{pdr}$ and the corresponding $d$. Evaluate for $h = 1$.

In plain words
Same method as P9 for the NOR3. The slow edge is now the rising one through three series PMOS.
Theory
4.6 (NOR3 table), Recipe E.
Plan
Output $9C + 7hC$; internal PMOS nodes $6C$ each, at $\frac R3$ and $\frac{2R}{3}$ from $V_{DD}$.
Solve
  1. $t_{pdf} = (9+7h)RC + 6RC + 6RC = (21+7h)RC$ → $d = 7 + \frac73h$; $h = 1$: 28 RC, d = 9.33
  2. $t_{cdf} = (9+7h)C\cdot\frac R3$ → $d = 1 + \frac79h$; $h = 1$: 5.33 RC, d = 1.78
  3. $t_{pdr} = (9+7h)RC + 6C\cdot\frac{2R}{3} + 6C\cdot\frac R3 = (15+7h)RC$ → $d = 5 + \frac73h$; $h = 1$: 22 RC, d = 7.33
Check
Slope $\frac73$ = $g_{NOR3}$ ✓. Compare P9: NOR3 is slower than NAND3 for the same $h$, which is why designers prefer NANDs.

P11 · Drive and input capacitance of sized gates In lectures

Find the normalised input capacitance and the drive $x$ of (a) INVX4, (b) NAND2X2, (c) NOR3X2, (d) NAND3X4. Then find $d$ for the NAND2X2 driving a load of 12 (in unit-inverter input caps).

In plain words
"X2" means every transistor is twice as wide as the unit-drive version. How much input cap, and how much current?
Theory
5.3: $x = C_{in}/g$ with $C_{in}$ in units of $3C$; $d = C_{out}/x + p$.
Plan
Unit-drive input cap × size → divide by 3 → divide by $g$.
Solve
  1. INVX4: $C_{in} = 4\times3C = 12C$ → 4; $x = 4/1 =$ 4
  2. NAND2X2: $2\times4C = 8C$ → $8/3$; $x = \frac{8/3}{4/3} =$ 2
  3. NOR3X2: $2\times7C = 14C$ → $14/3$; $x = \frac{14/3}{7/3} =$ 2
  4. NAND3X4: $4\times5C = 20C$ → $20/3$; $x = \frac{20/3}{5/3} =$ 4
  5. NAND2X2 driving 12: $d = \frac{12}{2} + 2 =$ 8 (check: $h = 12/(8/3) = 4.5$, $gh = \frac43\times4.5 = 6$ ✓)
Check
The drive is always the "X" number: that is what X means ✓.

P12 · Path effort with branching (Lecture 34 example) In lectures

An inverter of input capacitance 5 drives two inverters of input capacitance 15. Each of those drives a load of 90. For the path through one branch find $f_1$, $f_2$, $F$, $G$, $H$ and $B$, and show that $F = GBH$. Find the path delay.

In plain words
The first inverter feeds two branches, but we only care about one path. Does $F = GH$ still work?
Theory
6.2–6.3: $F = \prod f_i$; $b = (C_{on}+C_{off})/C_{on}$; $F = GBH$.
Plan
Stage efforts from the real loads, then compare with $G\cdot H$.
Solve
  1. $f_1 = 1\times\frac{15+15}{5} = 6$; $f_2 = 1\times\frac{90}{15} = 6$ → $F = 36$.
  2. $G = 1\times1 = 1$; $H = 90/5 = 18$ → $GH = 18 \ne F$.
  3. $b_1 = \frac{15+15}{15} = 2$, $b_2 = 1$ → $B = 2$ → $GBH = 36 = F$ ✓
  4. $D = f_1 + f_2 + p_1 + p_2 = 6 + 6 + 1 + 1 =$ 14 τ
Check
Both stages already have $f = 6 = \sqrt{36}$: this path is already optimally sized ✓.

P13 · Is sizing worth it? Unsized vs optimised path In lectures

For the Lecture 34 path (inverter 10 → NOR2 x → NAND2 y → inverter z → load 45), find the delay if all gates are left at input capacitance 10 ($x = y = z = 10$), and compare with the optimum.

In plain words
What if we don't bother sizing? Add up the four stage delays with every input cap = 10.
Theory
$d_i = g_ih_i + p_i$; 6.4 for the optimum ($\hat D = 13.1\tau$).
Plan
For each stage: $h = $ next input cap ÷ own input cap.
Solve
  1. Stage 1: $1\times\frac{10}{10} + 1 = 2$.   Stage 2: $\frac53\times\frac{10}{10} + 2 = 3.67$.
  2. Stage 3: $\frac43\times\frac{10}{10} + 2 = 3.33$.   Stage 4: $1\times\frac{45}{10} + 1 = 5.5$.
  3. $D = 2 + 3.67 + 3.33 + 5.5 =$ 14.5 τ, vs 13.1 τ optimised (about 10% faster).
Check
The unsized path makes the last stage work hardest ($f = 4.5$) while the others loaf ($f \approx 1$–$1.7$). Equalising them to $1.78$ each is what saves time ✓.

P14 · Size a path with branching In lectures

An inverter with input capacitance 10 drives a NAND2. The NAND2 drives three identical NOR2 gates; the path continues through one of them, which drives a load of 120. Find $G$, $B$, $H$, $F$, the best stage effort, the minimum delay, and the input capacitance of the NAND2 and NOR2.

In plain words
A three-stage path where the middle gate also feeds two side branches. Size it for minimum delay.
Theory
6.2–6.4: $F = GBH$, $\hat f = F^{1/N}$, $\hat D = N\hat f + P$, $C_{in} = gC_{out}/\hat f$.
Plan
Path numbers → $\hat f$ → walk backwards from the 120 load.
Solve
  1. $G = 1\times\frac43\times\frac53 = \frac{20}{9}$; $B = 3$ (three equal branches); $H = 120/10 = 12$.
  2. $F = \frac{20}{9}\times3\times12 = 80$; $\hat f = 80^{1/3} = 4.31$; $P = 1 + 2 + 2 = 5$.
  3. $\hat D = 3\times4.31 + 5 =$ 17.9 τ
  4. NOR2: $C_{in} = \frac{\frac53\times120}{4.31} =$ 46.4. NAND2 drives $3\times46.4$: $C_{in} = \frac{\frac43\times139.2}{4.31} =$ 43.1.
  5. Check the inverter: $\frac{1\times43.1}{4.31} = 10$ ✓
Check
Forgetting $B$ gives $F = 26.7$ and gates that are too small ✓ (a classic mistake).

P15 · How many inverters to drive a big load? Optional

A unit inverter (input cap 1) must drive a load of 1000 through a chain of inverters. Find the delay for N = 2, 3, 4, 5, 6 stages and the best N.

In plain words
More stages share the work, but each adds its own parasitic delay. Find the sweet spot.
Theory
6.4: $F = H = 1000$, $G = B = 1$, $\hat D = NF^{1/N} + N\,p_{inv}$.
Plan
Evaluate for each N.
Solve
N = 2: 65.2; 3: 33.0; 4: 26.5; 5: 24.9 τ (best); 6: 25.0. Best stage effort $1000^{1/5} = 3.98 \approx 4$.
Check
$\log_4 1000 = 4.98 \approx 5$ ✓ (the "stage effort ≈ 4" rule).
