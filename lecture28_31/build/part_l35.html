7 · Lecture 35: sizing a branched path, and the best number of stages In lectures

Lecture 35 does a full worked example of Lecture 34's method on a path with branches, turns the answers into real transistor widths, and then asks: if I may add inverters, how many stages give the shortest delay?

7.1 The worked path: NAND2 → NAND3 → NOR2 → 45

In plain words
Find the fastest possible delay from A to B, and the sizes x and y that give it.
Plan
Recipe I: write g and p under each gate → G, B, H → F → f̂ → D → walk backwards.
Solve
  1. $G = g_1g_2g_3 = \frac43\cdot\frac53\cdot\frac53 = \frac{100}{27}$.
  2. Branching: the NAND2 output feeds $x + 2x$ but only $x$ is on the path → $b_1 = \frac{x+2x}{x} = 3$. The NAND3 output feeds $y + y$ → $b_2 = 2$. So $B = 3\times2 = 6$.
  3. $H = \dfrac{C_{load}}{C_{in}} = \dfrac{45}{8}$.
  4. $F = GBH = \frac{100}{27}\times6\times\frac{45}{8} = 125$, so $\hat f = 125^{1/3} =$ 5.
  5. $P = 2 + 3 + 2 = 7$, so $\hat D = 3\times5 + 7 =$ 22 τ.
  6. Backwards, $C_{in} = g\,C_{out}/\hat f$: NOR2 $y = \frac{\frac53\times45}{5} =$ 15; NAND3 drives $y + y = 30$: $x = \frac{\frac53\times30}{5} =$ 10; check the NAND2: it drives $3x = 30$: $\frac{\frac43\times30}{5} = 8$ ✓ (the given input cap).

7.2 From input capacitance to transistor widths

A gate sized "k times unit" has every width multiplied by k, and its input cap multiplied by k. Unit-drive input caps: NAND2 $4$, NAND3 $5$, NOR2 $5$ (in units of $C$).

Recipe: Cin → widths
  1. Unit-drive widths: NAND-n: NMOS n, PMOS 2; NOR-n: NMOS 1, PMOS 2n; inverter: NMOS 1, PMOS 2.
  2. Unit input cap = NMOS width + PMOS width (NAND2 4, NAND3 5, NOR2 5, NOR3 7, inverter 3).
  3. $k = C_{in}/(\text{unit input cap})$, then multiply every width by $k$.
Units: watch out In this lecture "8", "45", "15" are in units of $C$ (one unit transistor's gate cap): an inverter input is 3. In Tutorial 10 Q4 the unit is one inverter input. Both work, as long as $C_{in}$, $C_{out}$ and the widths use the same unit.

Intuition Adding an inverter costs a fixed $p_{inv} = 1$ but divides the work. While $\hat f$ is large (above about 4), splitting it helps more than the extra parasitic costs. Below about 3.6, it no longer pays.

7.4 The best stage effort ρ (derivation from Lecture 35)

Suppose a path of $n_1$ logic gates can be padded with extra inverters to reach $N$ stages. Then

$$D = N F^{1/N} + \sum_{i=1}^{n_1} p_i + (N - n_1)\,p_{inv}$$

Differentiate with respect to $N$ and set it to zero (with $\rho = F^{1/N}$, so $\frac{d}{dN}F^{1/N} = -\frac{\ln F}{N^2}F^{1/N}$):

$$\frac{\partial D}{\partial N} = -F^{1/N}\ln F^{1/N} + F^{1/N} + p_{inv} = 0\quad\Longrightarrow\quad \rho\,(1 - \ln\rho) + p_{inv} = 0$$
Memorise $$\rho = 3.59\ (p_{inv} = 1),\qquad \hat N = \log_\rho F = \frac{\ln F}{\ln\rho}\approx\log_4 F$$ Example: $F = 64$: $\log_4 64 = 3$ stages ✓ (option C). Round $\hat N$ to a whole number; if the path must invert (or not), pick the nearest $N$ with the right parity.
Say it out loud "Best stage effort is about 4: so the number of stages is log base 4 of the path effort."

8 · Lecture 36: combinational logic, complex and asymmetric gates In lectures

8.1 Many ways to build F = AB + CD

Bubble pushing (De Morgan in pictures) $\overline{A\cdot B} = \bar A + \bar B$: a NAND is an OR with bubbles on its inputs. $\overline{A + B} = \bar A\cdot\bar B$: a NOR is an AND with bubbles on its inputs. So AND → OR becomes NAND → (OR with bubbled inputs) = NAND → NAND.

8.2 Which version is faster? (Lecture 36 comparison)

Both versions drive a load with path electrical effort $H = 5$ and have two stages:

Version$G$$F = GH$$P$$\hat D = 2\sqrt F + P$
AOI22 + inverter$2\times1 = 2$10$4 + 1 = 5$$2\sqrt{10} + 5 = 11.3\,\tau$
NAND2 + NAND2$\frac43\times\frac43 = \frac{16}{9}$$\frac{80}{9}$$2 + 2 = 4$$2\sqrt{80/9} + 4 =$ 9.96 τ

The NAND–NAND version wins: an AOI22 has big series stacks, so both its $g$ (2) and $p$ (4) are high. Complex gates save area and transistors, but are not always faster.

8.3 AOI21 and its average logical effort

Input caps: A and B: $2 + 4 = 6$ → $g_A = g_B = 2$. C: $1 + 4 = 5$ → $g_C = 5/3$. Output diffusion: PMOS C 4 + NMOS A 2 + NMOS C 1 = 7 → $p = 7/3$. Average: $g_{avg} = \frac{2 + 2 + 5/3}{3} = \frac{17}{9} \approx 1.89$.

8.4 A bigger one: Y = [A(B + C) + DE]'

A smarter sizing than "longest path" The longest-path rule (Recipe B2) would give B, C, D, E width 6 and A width 4. The lecture shares the resistance budget instead: D, E are 6 ($R/3$ each), so the top part may use $2R/3$. B and C in series each get $R/3$ (width 6); A alone gets $2R/3$, so width 3 is enough. Every path still totals exactly $R$, and A's input cap drops from 6 to 5. Both answers are valid; the lecture's is slightly better.

Results: $g_A = \frac{2+3}{3} = \frac53$; $g_B = g_C = g_D = g_E = \frac{2+6}{3} = \frac83$; output diffusion $6 + 6 + 2 + 2 = 16$ → $p = \frac{16}{3}$.

8.5 Asymmetric gates

Idea A series stack only needs a total of $R$. Split it unevenly: A gets $3R/4$ (width 4/3), RESET' gets $R/4$ (width 4). Now $g_A = \frac{4/3 + 2}{3} = \frac{10}{9}$, lower than the normal $\frac43$, so the critical signal sees a lighter gate. RESET' pays: $g = \frac53$, but it is not timing-critical.

8.6 Input positioning

In a series stack the transistors are not equal. If the inner input (nearest ground) arrives early, the internal node is already discharged; when the outer input finally switches, only the output has to fall. That is the fast case ($t_{cd}$ in 4.5). So: connect the latest-arriving (critical) signal to the transistor nearest the output.

9 · Lecture 37: skewed gates, ratioed gates and pseudo-NMOS In lectures

9.1 Skewed gates: favour one edge

Sometimes only one edge is critical (for example, a rising edge that triggers something). A skewed gate shrinks the transistor of the unimportant edge. That lowers the input capacitance, so the important edge gets faster.

How to find gu and gd (the lecture's method) Rising edge ($g_u$): find an unskewed inverter with the same PMOS (same rising current), and divide input caps.
Falling edge ($g_d$): find an unskewed inverter with the same NMOS (same falling current), and divide input caps.
HI-skew inverter (PMOS 2, NMOS ½, input cap 2.5):
  • same PMOS as the unit inverter (cap 3) → $g_u = \frac{2.5}{3} = \frac56$
  • same NMOS as an inverter (PMOS 1, NMOS ½), cap 1.5 → $g_d = \frac{2.5}{1.5} = \frac53$
  • $g_{avg} = \frac{5/6 + 5/3}{2} = \frac54$; $p_u = \frac56$, $p_d = \frac53$ (same ratios, applied to the diffusion cap 2.5)
LO-skew inverter (PMOS 1, NMOS 1, cap 2): $g_u = \frac{2}{1.5} = \frac43$, $g_d = \frac23$.
Worked: HI-skew NAND2 (lecture) PMOS 2, 2; NMOS 1, 1 (series: $R + R = 2R$ → falling current halved). Input cap $2 + 1 = 3$. Rising: same current as the unit inverter (cap 3) → $g_u = 3/3 = 1$. Falling: current of an NMOS of width ½ → compare with the (1, ½) inverter (cap 1.5) → $g_d = 3/1.5 = 2$. Parasitic: output diffusion $2 + 2 + 1 = 5$ → $p_u = 5/3$, $p_d = 5/1.5 = 10/3$.

9.2 Ratioed gates

In a ratioed gate the pull-up is always on. When the NMOS turns on, the two fight, and the output low level is set by the ratio of their strengths. This is exactly Razavi's common-source stage with a resistive load (§3.3.1): in deep triode $V_{out} = V_{DD}\dfrac{R_{on}}{R_{on} + R_D}$ (Razavi Eq. 3.6).

9.3 Pseudo-NMOS

Pros and cons + only N + 1 transistors for an N-input gate; low input capacitance (no PMOS on the inputs), so fast for wide NORs.
− $V_{OL} > 0$; static current flows whenever the output is low (power); the rising edge is slow because the PMOS is weak.
Lecture 37 sizing rule Choose the PMOS 4× weaker than the NMOS (width $x/2$ against $x$, and PMOS mobility is half). At $V_{out} = V_{DD}/2$ the net pull-down current must equal a unit inverter's: $$\frac{V_{DD}/2}{R/x} - \frac{V_{DD}/2}{2R/(x/2)} = \frac{V_{DD}/2}{R}\;\Rightarrow\; x - \frac x4 = 1\;\Rightarrow\; x = \frac43$$ NMOS $\frac43$, PMOS $\frac23$.
Optional (Weste & Harris): its g and p Input cap $\frac43$. Falling: same net current as a unit inverter (cap 3) → $g_d = \frac{4/3}{3} = \frac49$. Rising: the PMOS gives $\frac13$ of a unit current → compare with an inverter of cap 1 → $g_u = \frac43$. Diffusion $\frac43 + \frac23 = 2$ → $p_d = \frac23$, $p_u = 2$.
